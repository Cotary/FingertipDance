# 2026 副业路线：Go 开发者的三条线

> 目标：稳定月入 **3~5 千**（不是爆款，是可复现的现金流 + 一条有期权的资产线）
> 制定日期：2026-11-01　　主战场：微信/抖音小游戏 + 素材生产 + Go 外包

---

## 0. 核心结论（先看这个）

| 问题 | 结论 |
|---|---|
| 视频搬运 vs 做游戏，哪个更来钱 | **搬运的"钱"来自平台补贴（可随时收回），游戏的"钱"来自广告主预算（长期存在）**。搬运在 2026 更接近高风险灰产，不是稳定副业 |
| 你的 Go 技能在两边哪个更值钱 | **游戏侧**。Go = 房间/排行/AB/埋点/支付/反外挂的核心资产；搬运侧 Go 只能做流水线，而流水线恰恰是平台风控重点打击对象 |
| 能不能两者都做 | 能，但**不是并行**，是**串联**：用 Go 做"程序化素材工厂"喂自己的小游戏。素材产能 = 小游戏收入天花板 |
| 3~5 千/月 现实吗 | **现实，但必须双引擎**：现金流靠接单/工具（1~2 个月见效，贡献 60~70%），期权靠小游戏（6~12 个月，贡献 0~3 千） |
| 最小可行第一步 | 本周：① 接单渠道开通 ② 素材工厂 v0（纯 Go，不依赖游戏本体） |

## 1. 为什么不做"搬运"做主线

### 1.1 钱的性质不同

| | 搬运/二创号 | 小游戏 |
|---|---|---|
| 收入来源 | YouTube YPP / TikTok 创作者基金 / 品牌合作 | 广告主真实预算（IAA 激励视频、eCPM） |
| 抗规则变化 | ❌ 极差。YouTube 对 "reused content" 有明确降权与分成资格限制，TikTok 创作者基金仅部分地区开放 | ✅ 强。广告预算是长期存在的 |
| 单位收益 | 100 万播放 ≈ 几十~几百元 | eCPM 数十元/千次激励视频播放；ARPDAU 可达 0.1~0.5 元 |
| 现金流 | 快（1~2 周） | 慢（2~6 个月） |
| 失败模式 | 版权投诉 / 批量判定 → 矩阵账号一起死 | 玩法不成立 → 投流烧完 |
| 天花板 | 低（月入几千到 2 万后极难突破，且依赖账号存活） | 高（爆款月入 10w+ 不罕见） |

### 1.2 你的 Go 在搬运侧是"负杠杆"

Go 可以帮你做"批量下载 → 转码 → 去重 → 多账号自动发布"，但：
- 平台的反自动化识别（设备指纹、行为节奏、素材指纹）**专门针对这类脚本化操作**
- 你越自动化，越容易被判定为批量异常 → 省下的人力全部喂给风控
- 而且它不产生复利：素材不是你的资产，账号不是你的资产

**结论**：搬运不作为主线。若保留，只做"垂直 + 本地化 + AI 配音/重剪"的半原创矩阵，定位为内容感觉的练手场和引流渠道，**不把账号资产押上去**。

## 2. 三条线的具体设计

### 线 A｜现金流主线：Go 接单 + 出海小工具（目标 2~3.5 千/月，1~2 个月达成）

#### A1. 接单方向（按你的技能匹配度排序）

| 方向 | 单价区间 | 交付物 | 你的优势 |
|---|---|---|---|
| **小游戏后端定制/接入陪跑** | 3000~15000/单 | 基于 plan 里的 L1/L2 通用层，加新游戏目录即可 | 你正在自建一套，别人要现成的 |
| 微信/抖音小游戏「登录+支付+广告+排行榜+排行榜分享」接入 | 1000~5000/单 | Adapter 实现 + 部署 | 典型卡点，交付确定 |
| Go 后端外包（API 网关 / 高并发 / 定时任务 / 对账） | 按人天 800~2000 | 服务代码 + 文档 | 主业技能直接变现 |
| 数据采集/爬虫（合规范围内） | 按条计价 | 采集器 + 清洗入库 | 注意：只做公开数据、不碰个人隐私/版权内容 |
| DevOps / 部署 / 监控 / 成本优化 | 500~3000/单 | 脚本 + 文档 | 上云成本是普遍痛点 |

#### A2. 出海小 SaaS（Go + Stripe 收款，选 1 个做）

选题原则：**你自己是目标用户**（做小游戏的人）、**痛点高频**、**能纯后端实现**、**不需要美术**。

- 🎯 **首选：小游戏买量 ROI 归因与素材效果看板**
  素材 530 条、广告计划 1400+——素材级归因是真痛点，且纯数据后端，Go + ClickHouse/PG 完全够用
- 🎯 **备选：Steam 开发者发行/愿望单/收入看板**（面向独立开发者，订阅制 $9~19/月）
- 🎯 **备选：小游戏 AB 实验平台**（配置驱动 + 指标 + 灰度），你 plan 里的 Config/Analytics 直接就是原型

> ⚠️ A2 的定位是"做游戏过程中顺手长出来的工具"，**不要先做 SaaS 再想游戏**。第一个 SaaS 应该从你小游戏 MVP 的真实需求里长出来。

#### A3. 接单铁律（不做这三条会翻车）

1. **合同化**：明确需求边界、修改次数（≤2 次）、交付周期、源码归属
2. **先收 30~50% 定金**，小单全款
3. **交付即弃**：只给 Docker 镜像 + 文档 + 一段 30 分钟培训，**不做长期驻场**（售后是最吞时间的黑洞）
4. **不接"改到满意为止"**——这类单最后一定是亏的

### 线 B｜技能杠杆：程序化视频素材工厂（Go + ffmpeg）

#### 核心洞察

《占城大师》海外原型投放 **530 条素材 / 1400+ 广告计划 / 预估 1.39 亿浏览**，其中"一键清怪"细分方向仅 50 条素材却对应 2663 万曝光。

**结论：素材不是营销附属品，是产能杠杆。** 低成本变体（换一个地貌背景 = 一条新素材）是同一套玩法的规模放大器。这正好是"搬运"想追求的效果（量产素材），但**用完全不同的路径实现，且完全拥有、不侵权、可以喂自己的游戏**。

#### 技术方案（纯 Go，不依赖游戏本体）

```
素材工厂 v0（Go）
├─ render/       纯 image/draw 绘制帧序列（抽象几何风：色块/圆弧/粒子/数字）
│                · 抽象几何风格 → 无需美术资源，纯代码绘制（与 plan 7.2 的 PIL 思路一致）
│                · 固定随机种子 → 同一模板产出可复现变体
├─ template/     参数化模板：背景地貌 / 色板 / 布局 / 文案 / 节奏曲线
│                变体维度：地貌(水域/旷野/岛屿/草原) × 色板 × UI 布局 × 时长 × 文案
├─ compose/      ffmpeg 合成：PNG 序列 → mp4（可选 AI 配音 + 字幕烧录）
├─ variant/      去重与指纹管理：帧差、色彩直方图相似度、感知哈希去重
├─ publish/      素材元数据 + 投放回流数据 → 效果排名（哪些变体 CTR 高）
└─ cli/          matgen build --template x --variants 200 --out ./out
```

> 抽象几何风是这个方案的**技术红利**：纯色块 + 粒子 = 纯代码绘制，不需要任何美术资产，也不涉及搬运素材的版权问题。

#### 变现路径（三个，优先级从高到低）

1. **自用**：给自己的小游戏产出 50~100 条素材做 CTR/留存 A/B（这本身就是游戏 MVP 的必要输入，不是副业变现）
2. **卖同行**：给做小游戏/短剧投量的团队做"程序化素材代生产"，按条或按月打包收费。**这是最快变现的一条**——你卖的是产能，不是创意
3. **卖工具**：把 `matgen` 本身做成 SaaS 或开源引流（开源引流 → 引流 → 接单/卖素材）

#### 起步节奏

- 第 1 周：`render/` 出第一帧 PNG → 能看到圆点+数字+辉光（对齐截图风格）就算成功
- 第 2 周：模板参数化 + ffmpeg 合成出 10 条 mp4
- 第 3~4 周：去重 + 批量 → 200 条变体 + 效果记录表

**先决条件**：需要装 ffmpeg（当前机器未安装）。素材工厂完全独立于游戏，可与线 C 并行。

### 线 C｜期权主线：微信/抖音小游戏（目标 0~3 千/月，6~12 个月）

沿用 `小游戏通用框架与圈地扩张游戏_a3c179d5.plan.md`，不做改动，只在此处补充**收入倒推**和**本路线图的约束**。

#### 收入倒推（3~5 千/月需要什么）

```
微信 IAA 分成 50%（创意小游戏 200 万内 70%）
抖音 IAA（2026-11-01 起）投广场景 90% / 非投广 60% + 投放金 5% + 任务金 20%

目标净收入 3~5 千/月
  → 需平台流水 ≈ 0.6~1.0 万/月（按 60% 综合分成）
  → 需 ARPDAU ≈ 0.1~0.3 元（激励视频为主）
  → 需稳定 DAU ≈ 2 万~5 万
```

**这是本路线最关键的一个数字**：3~5 千/月 ≈ **稳定 2~5 万 DAU**。它证明了：

1. **不能指望小游戏单独撑起 3~5 千/月**——必须靠线 A 兜底
2. 小游戏的正确定位是**期权**：一旦跑通社交裂变（微信官方数据：社交做得好的新增占比 55%→87%、留存 88%），DAU 才有可能爬到量级；跑不通就止损回到线 A
3. **判据必须前置**：Phase 2 原型阶段就要看 5 个真人试玩的次留意愿，而不是等上线后看数据

#### 本路线给线 C 的三条硬约束

1. **必须 IAA-only，不碰版号**（个人主体拿不到内购版号，周期 9~15 个月）
2. **必须复用线 B 的素材工厂**——没有素材产能的小游戏等于没有收入上限
3. **社交优先（擂台赛 + 自维护好友 + 异步可复现挑战）**：这是唯一能绕开买量成本拿到自然量的路径，而 buy 量正是 3~5 千/月目标最承受不起的支出

## 3. 6 个月排期（每周 10~12 小时）

| 月份 | 线 A（现金流） | 线 B（素材） | 线 C（游戏期权） | 预期月收入 |
|---|---|---|---|---|
| **M1** | 接单渠道开通（闲鱼/小红书/V2EX/掘金/电鸭），上架 3 个服务，上接 2 单 | `matgen render` 出第一帧，模板参数化 | Phase 1 工程骨架（Go monorepo + Cocos Web 版跑通登录） | 0~1.5k |
| **M2** | 交付 2~3 单，优化话术与报价；沉淀 1 个可复用交付模板 | 出 10 条 mp4 → 200 条变体 + 去重 | Phase 2 玩法原型（拖拽拉线出兵 + 种子地图 + 自动战斗） | 1.5~3k |
| **M3** | 开始卖"程序化素材代生产"给同行 | 素材工厂 v1（接入效果回流，开始有数据） | Phase 2 完成 + 5 人试玩录屏；接微信擂台赛组件 | 2.5~4k |
| **M4** | 稳定 2 单/月 + 1 个 SaaS 需求验证 | 跑 A/B：素材 CTR 数据反哺模板设计 | Phase 3 通用模块 + Phase 5 IAA 上线提审 | 3~4.5k |
| **M5** | 现金流稳定在 3k+，把接单压到半周 | 素材月产能 500+，成为自己小游戏的买量替代 | 上线数据迭代（留存/漏斗看板） | 3~5k |
| **M6** | 评估是否把素材工厂做成对外产品 | 对外售卖素材包 + 工具 | Phase 6 实时对战 or Steam 版评估 | 3.5~6k |

**止损线（提前定，避免沉没成本陷阱）**：
- M3 末线 A 未稳定到 2k/月 → 加大线 A 投入，线 C 降为周末兼职
- M4 末小游戏次留 < 40% → 线 C 冻结，只做线 A + 线 B
- M6 末线 A+B 稳定 ≥ 5k/月 → 副业目标达成，线 C 转为"长期期权"按季度迭代，不再占用日常时间

## 5. 风险清单

| 风险 | 概率 | 对策 |
|---|---|---|
| 接单被无限售后拖死 | **高** | 合同化 + 定金 + 交付即弃 + 修改次数上限 2 |
| 素材工厂做成"技术自嗨"没人买 | 中 | 先自用验证（喂自己游戏 CTR），再对外卖；找 3 个真实客户验证付费意愿 |
| 游戏玩法不成立 | **高** | Phase 2 就做真人试玩录屏；砍系统不砍手感；双模式不达标不启动模式 B |
| 小游戏 DAU 长期上不去 | **高** | 线 A 兜底（这是为什么不能只押游戏） |
| 平台/政策变化（分成下调、审核收紧） | 中 | 抖音 90% 投广场景 + 微信 70% 创意小游戏额度，用好政策窗口 |
| 版号卡住内购 | 中 | 第一版纯 IAA，零版号 |
| 搬运路线诱惑（快速见钱） | 中 | 不作为主线；只保留小规模练手，不投入账号资产 |
