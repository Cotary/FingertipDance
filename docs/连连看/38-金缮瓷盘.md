# 金缮瓷盘 · 第三套典藏（替代「冰晶王国」）

> 一句话：**把格子做成一片片瓷，把走过的路做成修补瓷器的金线。**
> 它不是「换了配色的棋盘」，是「一只被修好的盘」。

---

## 一、先认账：冰晶王国为什么撤了

「冰晶王国」上线不到一天就下线了。它的失败不是参数没调好，是**方向错了**，
而且错在一个我当时写进注释里、却没真正解决的地方：

| 病 | 表现 | 真正的原因 |
|---|---|---|
| 像调试图 | 70 个一模一样的六边形线框铺满屏幕 | **格子仍然只是「一个轮廓」**，没有实体、没有厚度、没有光 |
| 像胶带 | 走过的路是一条等宽的白带，从六边形上直接压过去 | 两种形状语言打架：格子是六边，路是圆头直带 |
| 空 | 上半屏是深蓝，下半屏更空 | 背景和盘没有关系，盘是「浮在夜空上的一块板」 |
| 弱 | 图标像 16px 的 iconfont | 白底上留白太大，0.50 的图标漂在中间 |
| 灰 | 全是蓝，明暗只差一点点 | 只有「色相」没有「明度差」，就一定是脏的 |

最致命的是第一条。**只要格子还是「画个框」，不管换成六边形、圆形还是波浪形，
都只是「另一种网格」。** 所以这次不从形状下手，从**材质**下手。

---

## 二、选题：还能设计什么

把「连连看」的视觉结构拆开看，只有四样东西**占面积**：

1. 格子（约占 70% 的画面）
2. 格子里的图案（识别的关键）
3. 走过的路径（唯一会变的东西）
4. 背景（气氛）

冰晶王国的错误是想靠「2」和「4」救「1」。而真正能救的是让「1」本身变成实物。

按这个思路，我列了 11 个候选，最后按三条筛：

- **语义同构**：玩法和主题要讲同一件事，不是「贴个皮」
- **窄色域**：颜色越少越贵气，五个色以上必掉档
- **不怕重复**：70 个同构元素排在一起，能不能「耐看」

| 方向 | 语义 | 判定 |
|---|---|---|
| **金缮（碎瓷修补）** | **走过 = 修补** | ✅ 选中 |
| 博物标本盒 | 配对 = 找同种标本 | 很好，但要画 9 类博物画，工作量大 |
| 掐丝珐琅 | 金丝分格 = 天然格 | 好，但和「金线装饰」撞 |
| 活字印刷 | 走过 = 印上墨 | 和水墨撞 |
| 邮票册 / 拼布 / 马赛克彩窗 | 配对 / 缝线 / 铅条分格 | 都好，但都不如金缮「和玩法同构」 |
| 枯山水 / 青花 / 玉 / 青铜 / 珊瑚 | —— | 或太灰，或太冷，或不够「器」 |

**金缮赢在语义**：玩家本来就在画一条路径，而这条路径正好是「这只盘碎过的地方」。
修好它，盘就完整了 —— 连「通关」这件事都被解释了。

## 三、三根骨头（抽掉颜色也成立）

判据还是那一条：**灰度下认不认得出是另一套。**

1. **格子是「片」，不是「格」。**
   盘面铺一层暖灰的釉（缝底），每片瓷比缝底亮、内缩 1.9px。
   画面里**没有一条网格线**，只有一片片瓷和片与片之间的缝。
2. **走 = 修。** 走过的片同时变两件事：片里染浓钴（分水），片缝填金（金缮）。
   只提亮 → 退回换色主题；只描金边 → 像「选中状态」。
3. **一切靠釉，不靠描边。** 高光、积釉、开片全用低透明度叠色。
   瓷器的边是「釉流过去积起来」的，不是画上去的。

## 四、瓷盘的五层白

一只白瓷盘不是「一块白」。少任何一层都会塌成「一张卡片」：

| 层 | 亮度 | 它代表什么 |
|---|---|---|
| 口沿金线 | 金 | 描金口，器物的边界 |
| 盘身外缘 | 最亮 | 受光的立面 |
| 盘沿斜面 | 中 | 从沿到面的过渡，**壁的厚度就在这 12px 里** |
| 盘面 | 最暗 | **缝底** —— 瓷片之间的暗全靠这一层的暗衬出来 |
| 盘下反光 | 极淡冷白 | 盘把光反射回桌上，盘才「有光」而不是「有边」 |

再加四样东西，盘才「在房间里」而不是「在真空里」：

- **委角**：四角各切一刀（`quadraticCurveTo` 接直边）。这是明清方盘的做法，
  也是「方器」和「卡片」的分界 —— 卡片是圆角矩形，方器是委角方。
- **回纹带**：盘沿上下各一排连续的雷纹。这是全画面**唯一一处「密」** ——
  盘心必须疏、盘沿必须密，画面才有「一只盘」的构图。密度均匀的东西一定是「程序生成的」。
- **方向光**：右下角压一档暖灰（alpha 0.14），盖住所有层（阴影不会绕开花纹）。
- **窗影**：一道斜射的光带从左上方切到盘心。它不照亮任何东西，
  只是「告诉眼睛这里有一扇窗」。

## 五、做错的六件事（都在本轮被截图否掉）

| 版本 | 做法 | 判词 | 改法 |
|---|---|---|---|
| 1 | 暖白瓷 `#F7F1E5` | 「一块牛皮纸板」—— 暖白大面积重复 = 旧纸 | 冷白 `#F5F4ED`（R 略高于 G/B，泛一点青） |
| 2 | 缝宽 `cell*0.048` | 「灰底上摆着一堆白瓷片」，又回网格感 | 收到 `cell*0.030`（1.9px）。真实镶嵌的缝细如发丝 |
| 3 | 冷灰缝底 `#CBCEC2` | 「灰色网格 + 白方块」 | 缝底改**暖灰** `#DAD8C9`：冷白压暖灰才是「瓷浮在釉上」 |
| 4 | 金线 `cell*0.14` | 「金色胶带」 | 收到 `0.115`，四遍（晕/体/亮/高光）才有「漆的厚度」 |
| 5 | 起点做朱红小印 | 「青花釉里红是另一个门类」，硬加红从「雅」掉到「民俗」 | 撤掉，改回钴蓝双圈 |
| 6 | 盘沿朱印 `13px` | 被委角的斜切裁掉一半，只剩一个红角 | 撤掉 |

第 5、6 条值得单独说：**我一度以为「万绿丛中一点红」是稳赚的**。
实际上青花的美就建立在「只有蓝白」上，加红不是点睛，是换了个工艺门类。
**克制也是设计的一部分** —— 一个 10px 的红方块在浅底上，读起来更像「报错」而不是「款」。

## 六、顺手修的两个真 bug

### 1. 底部导航栏不跟主题（影响**全部**深色主题）

`ui/nav.ts` 里背板写死 `CLAY.cream`、选中片写死 `CLAY.terracotta` ——
于是黑曜熔岩、赛博霓虹、深海荧光、金线装饰装备后，底部都是**一条奶油色板**，
像贴错了图。

改：`drawNav(ctx, active, now, chrome?)`，三档色全部从 `ThemeChrome` 取。

坑：**未选中项不能用 `chrome.inkSoft`**。它是「深色背景上的弱化正文」，
放在浅色背板上会直接消失。用 `chrome.pillInk` + `globalAlpha 0.55`。
另外 `clayBlock` 要 `ClayColor` 对象，`chrome.pill` 是字符串，必须过一遍 `clayFrom()`。

### 2. 主题陈列页把盘裁掉了（影响**全部**有盘沿的主题）

`ui/skins.ts` 的缩略图按 `cell = inner / N` 算，盘沿（`cell*0.52`）撑出窗口被裁 ——
预览变成「一张没有边框的格子图」，玩家看不到这套主题的「器」。

改：解 `cell*(N + 1.04) = inner`，给盘沿留位置。

## 七、声音：瓷磬的 2.76 比

`render/voice.ts` 新增 `KINTSUGI`。最容易撞的是玻璃穹顶（同为「硬而亮的敲击」），
所以刻意走另一条物理路线：

| | 玻璃穹顶 | 金缮瓷盘 |
|---|---|---|
| 发声体 | FM，调制比 3.52 | 正弦基频 + **2.76 比**的泛音 |
| 长度 | 2.6s，大厅 | 1.4s，房间 |
| 高频 | 一路亮到 12kHz | 阻尼 4.2kHz，亮的只有那一下 |

**2.76 是瓷磬的实测泛音比**（不是整数倍）。换成 3.0 → 管钟，换成 2.0 → 木琴。
这是「瓷」和「钟」的全部物理区别。

音阶用**羽调式**（A C D E G）：小三度的暧昧感，比五声大调「文」一档。
基频 587（D5）—— 659 已被像素街机占用（`test/voice.test.ts` 有一条
「主频两两不同」的硬断言，加主题时必须查）。

## 八、地图联动

`mapstyle.ts` 里的 `kintsugi` 有一条特殊处理：**世界色不往金混**。

默认规则是「世界色往路面色混 30%」。但这套的路是**金色**，
七个世界混完集体变「灰绿 / 灰紫」—— 金路旁边站着一排脏球。

所以给 `MapPalette` 加了两个字段 `worldTo` / `worldK`：

```ts
worldTo: '#C6D2DC',   // 冷瓷白
worldK: 0.46,
```

七个世界就成了「七只不同色的瓷球」，和金路是同一间屋子里的东西。

**地图上最重要的对齐**：棋盘里「走过 = 金线」，地图上「整条古路 = 金线」，
两边是同一件事 —— 这只盘被金漆补过的那道缝，就是玩家要走的那条路。

## 十一、还能再往前一步

1. **盘上的一道旧裂**：一道极淡的金线从盘沿蜿蜒进盘面，只在格子缝隙里露出 ——
   「这只盘碎过」的证据。技术上可行（plate 先画、格子后盖），但缝只有 1.9px，
   风险是看不出来或者看起来像 bug。
2. **走过格的分水笔触**：现在分水是线性渐变。真实的分水有「笔停下的地方更深」的边界，
   可以在片的某一侧加一道深钴的边。
3. **盘沿缠枝纹**：回纹是「规整的密」，缠枝是「流动的密」。后者更像青花，
   但需要真正画藤蔓，工作量大。
4. **音色的「瓷裂」**：break 现在是「噪声 + 下滑 + 闷响」，可以加一串
   「碎片的多次弹跳」（3~5 个间隔递增的短噪声）。
