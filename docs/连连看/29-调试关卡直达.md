# 29 · 调试 · 关卡直达

> 2026-11-11。测试环境专用：输关号直接进关，不用从第 1 关打上去。

## 为什么做

地图页在开发构建下本来就允许点任意一关（`debugUnlockAll`），但地图是 1000 关的连续长卷：
**一屏 16 关，要测第 704 关得滑 40 多屏**。想对比「第 1 关和第 705 关的棋盘差多少」基本不可能，
只能改代码重启。

这个面板把「抵达某关」压成两次操作：**输关号 → 进入**。

## 长什么样

```
┌─────────────────────────────┐
│  调试 · 关卡直达        [关闭] │
│  [-]   [   705   ]   [+]     │  ← 预填当前关，第一下数字整段替换
│      星穹 · 705-1000 关       │  ← 副标题跟着关号变
│ [苗圃1][石溪13][苔原33][熔炉65]│
│ [深井153][云阶405][星穹705][随机]│ ← 七个世界边界没人记得住
│  [1] [2] [3]                 │
│  [4] [5] [6]                 │
│  [7] [8] [9]                 │
│  [退格] [0] [清空]            │
│  [      进入第 705 关      ]  │
└─────────────────────────────┘
```

## 三种入口

| 入口 | 场景 |
|---|---|
| 地图页右上角「调试」方块 | 手机 / 触摸，主路径 |
| 键盘 `` ` `` 或 `F2` | 桌面，任何页面随时呼出 |
| 面板内世界胶囊 | 不记得七个世界的边界号 |

「调试」方块放在右上角、和左边的「返回」按 30 边距对称。
**原来那块「调试 · 任意关可点」的说明牌宽 230，从 490 起，而关号胶囊右边缘在 495 ——
两者压在一起**，视觉上像胶囊右边沾了块膏药。顶部横向只剩 255 设计像素，
放不下整句说明，所以收成两个字，解释留给面板标题。

## 几个刻意的决定

**1. 首下输入整段替换（`fresh`）**

面板打开时预填当前关（大多数调试从「我卡在哪一关」出发），但直接往后接会让想输 71 的人得到 171。
`fresh = true` 时第一下数字清空重输；在预填值上按退格 = 整段丢掉，而不是删一位。
预填状态**不画光标** —— 光标暗示「可以往后接」，正好反了。

**2. 越界的那一下不接收，而不是先填进去再报错**

输入框里蹦出一个 9999，测试还得先删干净才能继续输。所以 `next > total` 时这次按键直接被丢弃，
底部闪一句「只有 1 - 1000 关」。

**3. 世界胶囊只填号、不直接进关**

直接进关省一次点击，但误触代价是「莫名其妙跳到第 705 关」。
填号后玩家还能继续改，或者直接按「进入」。

**4. 调试跳关不埋点**

测试行为混进线上的漏斗分析，比少一条事件糟得多。

**5. 面板是模态的**

展开时下面那一页一个都不许响应（`onDown` / `onMove` / `onUp` 都在最前面拦截）。
否则在关卡里打开面板、手指从面板上滑出去，就会拖到棋盘。
画序上它压在一切之上，但**在横屏提示之下** —— 横屏时该让「请竖屏」盖住它。

**6. 服务端失败也进关卡，但两种失败分开报**

- `403` → 「服务端调试未开启」（`debug.enabled: false`，自己关的）
- 其他 → 「服务端没响应」（后端没起 / DB 没开）

原来一律报前者。2026-11-11 实测 DB 容器挂掉时，这句提示把人往配置上带，白查半天。

## 生产包里有吗？没有

调用点全部包在 `DEBUG_ENABLED &&` 里，`DEBUG_ENABLED` 是构建期常量
（`vite.config.ts` 的 `define`，判据是 `command === 'serve'`，不是 `mode !== 'production'`
—— 微信构建用 `--mode wx`，按后者判断会把调试入口发进正式包）。

验证：

```bash
npm run build
grep -c "关卡直达\|dj:enter" dist/assets/*.js   # → 0
```

服务端另有一道独立开关（`server/deploy/config.local.yaml` 的 `debug.enabled`），
客户端绕过不算数。

## 顺手修的两件事

**登录不再无限等待。** 排查时发现：DB 不可用时后端不返回 500，而是**一直挂着**，
`fetch` 没有默认超时 → `boot()` 停在 `login()`，玩家看到的是「陶土背景 + 什么都没有」，
控制台干干净净。现在 web 端请求加 10 秒 `AbortController` 超时，
登录失败走已有的 catch → 用本地进度进大厅。微信端没动（`platform/wechat.ts` 各平台实现独立）。

**截图工具能看见异常了。** `tools/shot-cdp.mjs` 增加：
- `Page.addScriptToEvaluateOnNewDocument` 注入 `error` / `unhandledrejection` 收集
- `Runtime.exceptionThrown` + `console.error/warning` 汇总
- `EVAL="<表达式>"` 在页面里求值
- `AFTER_TAP` 最后一次点击后的额外等待

「截图一片空白」最常见的原因不是没渲染，而是运行时抛了异常 —— 而 CDP 截图本身不会告诉你。
