### 21.3 构建流程（把 TS 源码编译到微信工程）

在 `games/line/` 加一个构建脚本，把 `src/` 编译到 `games/line-wx/`：

```json
// package.json 的 scripts 加：
"build:wx": "vite build --mode wx && node scripts/copy-wx-assets.mjs"
```

`vite.config.ts` 改成多环境：
```ts
import { defineConfig } from 'vite';
import { resolve } from 'node:path';

export default defineConfig(({ mode }) => {
  const isWx = mode === 'wx';
  return {
    define: {
      __TARGET__: JSON.stringify(isWx ? 'wechat' : 'web'),
      __API_BASE__: JSON.stringify(process.env.API_BASE ?? 'http://127.0.0.1:8080'),
    },
    build: {
      target: 'es2017',
      outDir: isWx ? '../line-wx/dist' : 'dist',
      assetsInlineLimit: 0,
      rollupOptions: isWx ? {
        output: {
          format: 'iife',
          entryFileNames: 'game.js',
          inlineDynamicImports: true,
        },
      } : {},
    },
  };
});
```

**微信小游戏不支持 ES Module** → 必须打包成 IIFE 单文件。

`scripts/copy-wx-assets.mjs`：
```js
import { cpSync, mkdirSync, writeFileSync } from 'node:fs';
import { resolve, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';

const here = dirname(fileURLToPath(import.meta.url));
const wxDir = resolve(here, '../line-wx');

mkdirSync(resolve(wxDir, 'dist'), { recursive: true });
// game.json
writeFileSync(resolve(wxDir, 'game.json'), JSON.stringify({
  deviceOrientation: 'portrait',
  showStatusBar: false,
  networkTimeout: { request: 10000 },
}, null, 2));

console.log('微信工程资源已就绪:', wxDir);
```

### 21.4 写 `games/line-wx/game.js`（入口）

```javascript
// 微信小游戏入口。构建产物 dist/game.js 由 Vite 产出，
// 这里只做初始化与启动。
require('./dist/game.js');
```

> **注意**：微信小游戏**不支持 `<script type="module">`**，必须用 CommonJS 的 `require`。
> Vite 的 `format: 'iife'` 产出的文件会挂到全局；改为 `format: 'cjs'` 并在入口里 `require` 更稳。

**建议**：`rollupOptions.output.format = 'cjs'`，产物为 `dist/game.js`，`game.js` 里 `require('./dist/game.js')`。

### 21.6 平台适配层修正（**这是移植的核心工作量**）

#### 21.6.1 画布创建

`src/platform/wechat.ts` 的 `getCanvas()` 已经用 `wx.createCanvas()`。**但微信端 `game.js` 入口需要先创建主画布**：

```typescript
// src/platform/wechat.ts
getCanvas() {
  const sys = wx.getSystemInfoSync();
  const dpr = Math.min(sys.pixelRatio || 1, 3);
  const width = sys.windowWidth;
  const height = sys.windowHeight;
  // 微信小游戏第一个 wx.createCanvas() 返回主画布
  const canvas = wx.createCanvas();
  canvas.width = Math.floor(width * dpr);
  canvas.height = Math.floor(height * dpr);
  return { canvas, width, height, dpr };
}
```

#### 21.6.2 触摸事件

微信端**必须用 `wx.onTouchStart` 等**，不能 `addEventListener`。在 `src/main.ts` 里加平台分支：

```typescript
// src/main.ts
if (platform.name === 'web') {
  canvas.addEventListener('pointerdown', (e) => onDown(e.clientX, e.clientY));
  canvas.addEventListener('pointermove', (e) => onMove(e.clientX, e.clientY));
  canvas.addEventListener('pointerup', onUp);
  canvas.addEventListener('pointercancel', onUp);
} else {
  const wx = (globalThis as any).wx;
  wx.onTouchStart((e: any) => {
    const t = e.touches[0];
    if (t) onDown(t.clientX, t.clientY);
  });
  wx.onTouchMove((e: any) => {
    const t = e.touches[0];
    if (t) onMove(t.clientX, t.clientY);
  });
  wx.onTouchEnd(() => onUp());
  wx.onTouchCancel(() => onUp());
}
```

#### 21.6.3 坐标换算

微信触摸事件给的是**逻辑像素**，与 `sys.windowWidth` 同一坐标系 → 直接用：
```typescript
function toDesign(clientX: number, clientY: number): { x: number; y: number } {
  if (platform.name === 'wechat') {
    return { x: (clientX - offsetX) / scale, y: (clientY - offsetY) / scale };
  }
  // Web 端需要换算
  const rect = canvas.getBoundingClientRect();
  const px = (clientX - rect.left) * (canvas.width / rect.width);
  const py = (clientY - rect.top) * (canvas.height / rect.height);
  return { x: (px / dpr - offsetX) / scale, y: (py / dpr - offsetY) / scale };
}
```
> **这个分支在 T13/T14 已经做好了 —— 如果没有，现在补上。**

#### 21.6.4 离屏 canvas（分享海报）

```typescript
// src/ui/share.ts
function createCanvas(w: number, h: number): HTMLCanvasElement {
  if (platform.name === 'wechat') {
    const wx = (globalThis as any).wx;
    if (wx.createOffscreenCanvas) {
```

## 坑
- **微信小游戏不支持 ESM** → Vite 必须打包成 `cjs` 或 `iife`，不能留 `import`
- **必须用 `wx.onTouchStart`** → `addEventListener` 在微信端不存在
- **`wx.getSystemInfoSync` 已废弃**（新版基础库）→ 用 `wx.getWindowInfo()` + `wx.getDeviceInfo()`，但要兼容旧版 → 用 `getSystemInfoSync` 兜底
- **`wx.createCanvas()` 只能调一次拿主画布** → 后续的要用 `wx.createOffscreenCanvas`
- **小游戏切后台会销毁** → `onHide` 里必须落盘
- **`wx.request` 校验合法域名** → 本地开发要在开发者工具里勾选「不校验合法域名」
- **开放数据域的 `wx` 是子集** → 不能用主域的 API
- **`require` 路径要相对** → `game.js` 里 `require('./dist/game.js')`
