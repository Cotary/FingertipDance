# T23 — 大厅外壳与底部导航（主页 / 地图 / 排行 / 我的）

**目标**：把现在的「裸游戏循环」补成一个完整 App 外壳。

- 启动不再直接进关卡，而是进入 **主页大厅**
- 新增 **关卡地图页**（编号节点 + 星级 + 锁）
- 新增 **底部五页导航**（主页 / 地图 / 皮肤 / 排行 / 我的）
- 排行榜页拆成 **总榜 Tab + 好友榜 Tab**（总榜接上一直闲置的 `/api/leaderboard`）
- 新增 **我的页**（数据统计 + 皮肤收藏墙 + 设置）
- 双主题：大厅/地图/排行/我的用 **亮色卡通**，游戏内棋盘保留 **深色扁平**

**前置依赖**：T13（前端骨架）、T12（排行榜）、T16（皮肤）。**不需要**后端大改，只多一个只读接口。

**本任务不做**（明确排除，避免跑偏）：
- ❌ 不追求像素级还原参考图的 3D 星球 / 卫星节点 / 吉祥物 → 用 Canvas 2D 程序化**近似**
- ❌ 不引入任何图片 / 字体文件 → 继续零资源
- ❌ 不改关卡生成器 / 求解器 / 难度曲线 → 一个字都不动
- ❌ 不改数据库表结构（只加一个 GET 接口读已有 `level_records`）

```ts
/**
 * 画一个按钮并返回它是否被点击。
 * @param theme 主题，默认深色游戏主题
 */
export function drawButton(ctx: CanvasRenderingContext2D, b: Button, pressed: boolean, theme: Theme = COLORS): void {
  const scale = pressed ? 0.96 : 1;
  const cx = b.x + b.w / 2, cy = b.y + b.h / 2;
  ctx.save();
  ctx.translate(cx, cy);
  ctx.scale(scale, scale);
  ctx.translate(-cx, -cy);

  if (b.kind === 'primary') {
    ctx.fillStyle = theme.blue;
    roundRect(ctx, b.x, b.y, b.w, h(b), 24);
    ctx.fill();
    ctx.fillStyle = '#FFFFFF';
  } else if (b.kind === 'secondary') {
    ctx.strokeStyle = theme.blue;
    ctx.lineWidth = 2;
    roundRect(ctx, b.x, b.y, b.w, b.h, 24);
    ctx.stroke();
    ctx.fillStyle = theme.blue;
  } else {
    ctx.fillStyle = theme.border;
    roundRect(ctx, b.x, b.y, b.w, b.h, 24);
    ctx.fill();
    ctx.fillStyle = theme.text;
  }

  ctx.font = '600 32px system-ui, sans-serif';
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText(b.label, cx, cy);
  ctx.restore();
}
```

> ⚠️ 上面 `roundRect(ctx, b.x, b.y, b.w, h(b), 24)` 里的 `h(b)` 是笔误，**实际写 `b.h`**。实现时直接照抄原函数体，只把 `COLORS.xxx` 换成 `theme.xxx`、`'rgba(255,255,255,0.08)'` 换成 `theme.border`。

## 四、Step 2 — 底部导航 `ui/nav.ts`

新建 `games/line/src/ui/nav.ts`：

```ts
/**
 * 底部导航栏。主页 / 地图 / 皮肤 / 排行 / 我的 五个 Tab。
 * 全部 Canvas 绘制，零 DOM。
 */
import { DESIGN_W, DESIGN_H } from '../render/layout';
import { roundRect } from '../render/board';
import { LOBBY_THEME } from './theme';
import { Ease } from '../game/anim';

/** 导航页签。 */
export type NavTab = 'home' | 'map' | 'skins' | 'rank' | 'profile';

/** 全部页签，顺序即显示顺序。 */
export const NAV_TABS: NavTab[] = ['home', 'map', 'skins', 'rank', 'profile'];

/** 每个页签的文案。 */
export const NAV_LABELS: Record<NavTab, string> = {
  home: '主页',
  map: '地图',
  skins: '皮肤',
  rank: '排行',
  profile: '我的',
};

/** 导航栏高度（设计坐标系）。 */
export const NAV_H = 120;

/** 导航栏顶部 y。 */
export const NAV_TOP = DESIGN_H - NAV_H;

/** 单个页签宽度。 */
export const NAV_ITEM_W = DESIGN_W / NAV_TABS.length;

/** 一个页签的命中矩形。 */
export interface NavHit {
  tab: NavTab;
  x: number;
  y: number;
  w: number;
  h: number;
}

/** 计算所有页签的命中矩形。 */
export function navHitAreas(): NavHit[] {
  return NAV_TABS.map((tab, i) => ({
    tab,
    x: i * NAV_ITEM_W,
    y: NAV_TOP,
    w: NAV_ITEM_W,
    h: NAV_H,
  }));
}

/**
 * 判断点击落在哪个页签上。
 * @returns 页签名，没命中返回 null
 */
export function pickNavTab(x: number, y: number): NavTab | null {
  for (const h of navHitAreas()) {
    if (x >= h.x && x <= h.x + h.w && y >= h.y && y <= h.y + h.h) return h.tab;
  }
  return null;
}

/**
 * 绘制底部导航栏。
 * @param active 当前页签
 * @param now 当前时间戳（ms），用于图标动画
 */
export function drawNav(ctx: CanvasRenderingContext2D, active: NavTab, now: number): void {
  const t = LOBBY_THEME;

  // 背板 + 顶部投影
  ctx.fillStyle = t.shadow;
  ctx.fillRect(0, NAV_TOP - 8, DESIGN_W, 8);
  ctx.fillStyle = t.bgLight;
  ctx.fillRect(0, NAV_TOP, DESIGN_W, NAV_H);

  // 顶部分隔线
  ctx.fillStyle = t.border;
  ctx.fillRect(0, NAV_TOP, DESIGN_W, 2);

  navHitAreas().forEach((h, i) => {
    const cx = h.x + h.w / 2;
    const on = h.tab === active;
    const iconY = NAV_TOP + 44;
    const labelY = NAV_TOP + 92;

    // 选中项：浅蓝圆角底 + 轻微上浮
    if (on) {
      ctx.fillStyle = 'rgba(61,123,255,0.12)';
      roundRect(ctx, cx - 38, iconY - 30, 76, 68, 22);
      ctx.fill();
    }

    // 图标
    ctx.save();
    ctx.translate(cx, iconY + (on ? -3 : 0));
    drawNavIcon(ctx, h.tab, on ? t.blue : t.subText, now + i * 120);
    ctx.restore();

    // 文案
    ctx.textAlign = 'center';
    ctx.textBaseline = 'top';
    ctx.fillStyle = on ? t.blue : t.subText;
    ctx.font = on ? '600 24px system-ui, sans-serif' : '22px system-ui, sans-serif';
    ctx.fillText(NAV_LABELS[h.tab], cx, labelY);
  });
}

/**
 * 画一个导航图标（以原点为中心，约 44×44）。
 */
function drawNavIcon(ctx: CanvasRenderingContext2D, tab: NavTab, color: string, now: number): void {
  ctx.fillStyle = color;
  ctx.strokeStyle = color;
  ctx.lineWidth = 3;
  ctx.lineCap = 'round';
  ctx.lineJoin = 'round';

  switch (tab) {
    case 'home': {
      // 房子：三角屋顶 + 方形屋身
      ctx.beginPath();
      ctx.moveTo(-16, 2);
      ctx.lineTo(0, -14);
      ctx.lineTo(16, 2);
      ctx.stroke();
      ctx.fillRect(-11, 2, 22, 16);
      break;
    }
    case 'map': {
      // 路线：折线 + 三个节点
      ctx.beginPath();
      ctx.moveTo(-14, 14);
      ctx.lineTo(-4, -4);
      ctx.lineTo(6, 6);
      ctx.lineTo(15, -12);
      ctx.stroke();
      for (const [x, y] of [[-14, 14], [-4, -4], [6, 6], [15, -12]] as const) {
        ctx.beginPath();
        ctx.arc(x, y, 4, 0, Math.PI * 2);
        ctx.fill();
      }
      break;
    }
    case 'skins': {
      // 皮肤：2×2 圆角方块
      for (const [x, y] of [[-11, -11], [3, -11], [-11, 3], [3, 3]] as const) {
        roundRect(ctx, x, y, 9, 9, 2);
        ctx.fill();
      }
      break;
    }
    case 'rank': {
      // 奖杯：杯身 + 底座 + 把手
      ctx.beginPath();
      ctx.moveTo(-10, -14);
      ctx.lineTo(10, -14);
      ctx.lineTo(8, -2);
      ctx.quadraticCurveTo(0, 6, -8, -2);
      ctx.closePath();
      ctx.fill();
      ctx.fillRect(-3, 4, 6, 6);
      ctx.fillRect(-9, 10, 18, 4);
      // 把手
      ctx.beginPath();
      ctx.arc(-10, -9, 5, Math.PI / 2, Math.PI * 1.5);
      ctx.stroke();
      ctx.beginPath();
      ctx.arc(10, -9, 5, -Math.PI / 2, Math.PI / 2);
      ctx.stroke();
      break;
    }
    case 'profile': {
      // 人像：头 + 肩
      ctx.beginPath();
      ctx.arc(0, -8, 8, 0, Math.PI * 2);
      ctx.fill();
      ctx.beginPath();
      ctx.moveTo(-13, 16);
      ctx.quadraticCurveTo(0, -2, 13, 16);
      ctx.closePath();
      ctx.fill();
      break;
    }
  }
}
```

```ts
/**
 * 主页大厅。对应参考图 48_2.jpg。
 * 顶部玩家条 + 星球轨道 + 卫星关卡节点 + 吉祥物 + 大「开始游戏」按钮。
 * 全部 Canvas 绘制，零 DOM。
 */
import { DESIGN_W, DESIGN_H } from '../render/layout';
import { roundRect } from '../render/board';
import { drawButton, type Button } from './hud';
import { LOBBY_THEME } from './theme';

/** 主页状态。 */
export interface HomePageState {
  /** 已通过的最高关号 */
  maxLevel: number;
  /** 关卡总数 */
  levelCount: number;
  /** 昵称 */
  nickname: string;
  /** 头像 URL（空则程序化生成） */
  avatar: string;
  /** 已解锁皮肤数 */
  skinCount: number;
  /** 皮肤总数 */
  totalSkins: number;
}

/** 星球中心坐标与半径。 */
const PLANET = { x: DESIGN_W / 2, y: 540, r: 170 };

/** 轨道定义（半径比、倾角、起始相位）。 */
const ORBITS = [
  { k: 1.0, tilt: -0.22, phase: 0.0 },
  { k: 1.34, tilt: 0.18, phase: 1.1 },
  { k: 1.66, tilt: -0.1, phase: 2.3 },
];

/**
 * 绘制主页大厅。
 * @returns 可点击按钮列表
 */
export function drawHomePage(ctx: CanvasRenderingContext2D, st: HomePageState, now: number): Button[] {
  const t = LOBBY_THEME;

  // 背景：上浅下深的竖向渐变 + 装饰星点
  const bg = ctx.createLinearGradient(0, 0, 0, DESIGN_H);
  bg.addColorStop(0, '#DCE8FF');
  bg.addColorStop(0.45, t.bg);
  bg.addColorStop(1, '#E6ECFA');
  ctx.fillStyle = bg;
  ctx.fillRect(0, 0, DESIGN_W, DESIGN_H);
  drawStars(ctx, now);

  // ── 顶部玩家条 ──
  drawPlayerBar(ctx, st);

  // ── 星球 + 轨道 + 卫星节点 ──
  drawPlanet(ctx, now);
  drawOrbits(ctx, now);
  const nodes = satelliteLevels(st);
  for (const n of nodes) drawSatellite(ctx, n, now);

  // ── 吉祥物 + 气泡 ──
  drawMascot(ctx, now, st.maxLevel);

  // ── 进度条 ──
  const ratio = st.levelCount > 0 ? Math.min(1, st.maxLevel / st.levelCount) : 0;
  const barX = 60, barY = 992, barW = DESIGN_W - 120, barH = 14;
  ctx.fillStyle = 'rgba(34,48,77,0.10)';
  roundRect(ctx, barX, barY, barW, barH, barH / 2);
  ctx.fill();
  if (ratio > 0) {
    ctx.fillStyle = t.blue;
    roundRect(ctx, barX, barY, barW * ratio, barH, barH / 2);
    ctx.fill();
  }
  ctx.fillStyle = t.subText;
  ctx.font = '22px system-ui, sans-serif';
  ctx.textAlign = 'left';
  ctx.textBaseline = 'top';
  ctx.fillText(`第 ${st.maxLevel} 关`, barX, barY + 26);
  ctx.textAlign = 'right';
  ctx.fillText(`共 ${st.levelCount} 关`, barX + barW, barY + 26);

  // ── 大按钮 ──
  const label = st.maxLevel > 1 ? `继续 第 ${st.maxLevel} 关` : '开始游戏';
  const btn: Button = { x: 115, y: 1064, w: DESIGN_W - 230, h: 108, label, kind: 'primary', id: 'homeStart' };

  // 投影
  ctx.fillStyle = 'rgba(61,123,255,0.28)';
  roundRect(ctx, btn.x, btn.y + 6, btn.w, btn.h, btn.h / 2);
  ctx.fill();
  drawButton(ctx, btn, false, t);

  return [btn];
}

/** 画背景装饰星点（确定性伪随机，位置固定）。 */
function drawStars(ctx: CanvasRenderingContext2D, now: number): void {
  let s = 20261101;
  const rnd = () => ((s = (s * 1664525 + 1013904223) >>> 0) / 4294967296);
  for (let i = 0; i < 40; i++) {
    const x = rnd() * DESIGN_W;
    const y = 140 + rnd() * 800;
    const r = 1 + rnd() * 2;
    const tw = 0.4 + 0.6 * Math.abs(Math.sin(now / 900 + i));
    ctx.fillStyle = `rgba(255,255,255,${(0.25 + tw * 0.45).toFixed(3)})`;
    ctx.beginPath();
    ctx.arc(x, y, r, 0, Math.PI * 2);
    ctx.fill();
  }
}

/**
 * 画头像。有 URL 就画图（失败回退），没有就画程序化渐变 + 首字。
 */
export function drawAvatar(
  ctx: CanvasRenderingContext2D,
  cx: number,
  cy: number,
  r: number,
  url: string,
  name: string,
): void {
  const t = LOBBY_THEME;
  ctx.save();
  ctx.beginPath();
  ctx.arc(cx, cy, r, 0, Math.PI * 2);
  ctx.clip();
  const g = ctx.createLinearGradient(cx - r, cy - r, cx + r, cy + r);
  g.addColorStop(0, t.blue);
  g.addColorStop(1, t.purple);
  ctx.fillStyle = g;
  ctx.fillRect(cx - r, cy - r, r * 2, r * 2);
  ctx.fillStyle = '#FFFFFF';
  ctx.font = `600 ${Math.round(r * 0.9)}px system-ui, sans-serif`;
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText((name || '玩').slice(0, 1), cx, cy + 1);
  ctx.restore();

  // 白色描边
  ctx.strokeStyle = '#FFFFFF';
  ctx.lineWidth = 3;
  ctx.beginPath();
  ctx.arc(cx, cy, r, 0, Math.PI * 2);
  ctx.stroke();
}

/** 画星球本体。 */

/**
 * 计算大厅上要显示的卫星关卡节点。
 * 以当前关为中心，向前 3 关 + 向后 2 关，共 6 个。
 */
export function satelliteLevels(st: HomePageState): Satellite[] {
  const out: Satellite[] = [];
  const offsets = [-3, -2, -1, 0, 1, 2];
  for (const off of offsets) {
    const lv = st.maxLevel + off;
    if (lv < 1 || lv > st.levelCount) continue;
    // 均匀分布在 3 条轨道上
    const slot = out.length;
    const o = ORBITS[slot % ORBITS.length];
    const ang = o.phase + (slot / ORBITS.length) * Math.PI * 2;
    const rx = PLANET.r * o.k;
    const ry = PLANET.r * o.k * 0.34;
    const x = PLANET.x + Math.cos(ang) * rx;
    const y = PLANET.y + Math.sin(ang) * ry;
    out.push({
      level: lv,
      x,
      y,
      state: off < 0 ? 'done' : off === 0 ? 'current' : 'locked',
    });
  }
  return out;
}
```

```ts
/**

  const first = Math.max(1, Math.floor(scrollY / NODE_GAP) - 1);

  for (let i = first; i <= last; i++) {
    const p = mapNodePos(i);
    const cy = p.y - st.scrollY;
    const dx = x - p.x;
    const dy = y - cy;
    if (dx * dx + dy * dy <= 40 * 40) return i;
  }
  return -1;
}
```

### 10.1 新建 `server/internal/games/line/stars.go`

```go
package line

import (
	"strconv"

	"github.com/gin-gonic/gin"

	"github.com/tupss/f-game/server/internal/core"
)

// StarOf 按「步数 / 理论最短步数」算星级。
// 阈值必须与客户端 ui/hud.ts drawResult 保持一致。
func StarOf(steps, shortest int) int {
	if shortest <= 0 {
		return 1
	}
	ratio := float64(steps) / float64(shortest)
	switch {
	case ratio <= 1.15:
		return 3
	case ratio <= 1.5:
		return 2
	default:
		return 1
	}
}

// StarsHandler 返回玩家每关星级：{"stars": {"1": 3, "2": 2, ...}}
func StarsHandler(db *core.DB) gin.HandlerFunc {
	return func(c *gin.Context) {
		uid := core.UIDFromContext(c)

		rows, err := db.Query("SELECT level_idx, steps FROM level_records WHERE uid=$1", uid)
		if err != nil {
			core.Fail(c, core.CodeInternal, "查询星级失败: "+err.Error())
			return
		}
		defer rows.Close()

		stars := make(map[string]int, 64)
		for rows.Next() {
			var idx, steps int
			if err := rows.Scan(&idx, &steps); err != nil {
				continue
			}
			lv := Levels.Get(idx)
			if lv == nil {
				continue
			}
			stars[strconv.Itoa(idx)] = StarOf(steps, lv.Shortest)
		}

		core.OK(c, gin.H{"stars": stars})
	}
}
```

```ts
    if (id.startsWith('map:')) {
      const idx = parseInt(id.slice(4), 10);
      if (idx <= progress.current.maxLevel) {
        reportEvent('map_level_click', { level_idx: idx });
        await enterLevel(idx);
      } else {
        mapPage.toast = `先通过第 ${progress.current.maxLevel} 关`;
        mapPage.toastAt = Date.now();
      }
      return;
    }
    if (id === 'backHome') {
      phase = 'home';
      return;
    }
    if (id === 'tabGlobal') { rankPage.tab = 'global'; reportEvent('leaderboard_tab_switch', { tab: 'global' }); return; }
    if (id === 'tabFriends') {
      rankPage.tab = 'friends';
      reportEvent('leaderboard_tab_switch', { tab: 'friends' });
      void openFriends();
      return;
    }
    if (id === 'toggleSound') { profilePage.soundOn = !profilePage.soundOn; return; }
    if (id === 'toggleVibrate') { profilePage.vibrateOn = !profilePage.vibrateOn; return; }
    if (id === 'shareGame') { void doShare(); return; }
```

```ts
/**
 * 按「步数 / 理论最短步数」算星级。
 * 阈值必须与后端 server/internal/games/line/stars.go 的 StarOf 一致。
 */
export function starOf(steps: number, shortest: number): number {
  if (shortest <= 0) return 1;
  const ratio = steps / shortest;
  if (ratio <= 1.15) return 3;
  if (ratio <= 1.5) return 2;
  return 1;
}
```

## 十四、坑（务必先读）

1. **`main.ts` 里 `phase` 有 8 个值，`switch` 容易漏改。**
   改完后全局搜 `phase ===` 和 `phase !==` 逐个核对，特别是 `onUp` 里的 `if (phase === 'playing')` 分支 —— 原来「好友」页从游戏内按钮进，现在改成从底部导航进。

2. **删除 `friends` phase 会牵连 `friendsBtn`。**
   原来 `friendsBtn` 在游戏内左上角、`openFriends()` 切 `phase = 'friends'`。现在改成：游戏内换成 `backHomeBtn`；好友榜并入排行榜页的 Tab。改完必须确认 `frame()` 里没有残留的 `if (phase === 'friends')`。

3. **`drawNav` 会覆盖 `DESIGN_H - 120` 以下的区域。**
   所有大厅页面的内容高度必须留出 120 的底部安全区。地图页的 `VIEW_BOTTOM` 已经按 `DESIGN_H - 120` 定义。

4. **地图页拖动 vs 点击节点冲突。**
   必须用 `mapDragStart.moved` 区分：位移超过 6px 判定为拖动，松手时不进关。`mapDragStart` 的清理要放在 `onUp` 的 `if (pressedBtn)` 分支**之前**。

5. **`drawButton` 加了 theme 参数，所有既有调用点不用改**（默认深色）。但 `ui/skins.ts` 改成亮色后，**必须显式传 `LOBBY_THEME`**，否则会出现「亮色背景 + 深色按钮文字」看不清。

6. **`paintSkin` 的签名是 `(ctx, skin, x, y, w, h, seed, timeMs)`** —— 第 7 个参数是 seed 不是时间。收藏墙传 `i + 1` 当 seed。

7. **`ui/theme.ts` 的 `Game` 主题必须与原 `COLORS` 逐值一致**，否则游戏内配色会变。改完跑一遍游戏页对比。

8. **星级阈值必须前后端一致。**
   客户端 `ui/hud.ts` 的 `starOf` 与服务端 `server/internal/games/line/stars.go` 的 `StarOf` 是两份实现，靠 `test/stars.test.ts` + `stars_test.go` 双端锁定边界值。改一处必须改另一处。

9. **`fetchLeaderboard` 现在终于被调用了**，它走 `authed` 需要 token。如果 `boot()` 时 token 还没写进 storage（登录失败），拉到的是空榜。`loadGlobalRank` 已用 try/catch 包住，不会崩。

10. **`ProgressResult` 缺 `totalSteps` 字段** —— 现在要加。服务端 `progressResult` 结构体里**也没有** `totalSteps`，只有 `totalTimeMs`。如果「我的页」要显示总步数，需要在服务端 `progressResult` 里补 `TotalSteps int` 并在 `applyProgress` 里返回 `user.total_steps`（需要在读最新进度那行 SQL 里一起 SELECT 出来）。

11. **`config?.levelCount ?? 1000`** —— `config` 在登录成功前是 `null`，大厅建图前必须确保 `config` 已加载。`boot()` 里 `fetchConfig()` 在 `phase = 'home'` 之前，顺序正确。

12. **微信端 `wx.createCanvas()` 只能调一次。** 本任务不新增 canvas，沿用 `main.ts` 顶层的单例，**不要**在 `ui/*.ts` 里创建 canvas。

13. **`openDataContext/index.js` 里没有新逻辑要加。** 好友榜仍由开放数据域自己拉 `wx.getFriendCloudStorage`，主域只负责 `publishProfile`。如果只想让好友榜显示昵称，改 `main.ts` 的 `publishMyProfile` 就够了（见 9.3）。
