# T01 — 环境与工程骨架

**目标**：把 `games/line/` 建成一个能跑 `npm run dev` 的 TypeScript + Vite 工程，并让 `npm run typecheck` / `npm test` 通过（此时为空测试）。

**前置依赖**：无。

---

## 步骤

### 1.1 安装 Node LTS
```powershell
winget install OpenJS.NodeJS.LTS
# 安装后重开终端
node -v
npm -v
```
> 若已安装跳过。**Node < 18 直接停下来告知用户**。

### 1.2 初始化 git 仓库
```powershell
cd I:\work\f-game
git init
git add .
git commit -m "chore: init f-game monorepo"
```
> 如果 `git init` 报已有仓库，跳过。

### 1.3 创建目录骨架
```powershell
cd I:\work\f-game
New-Item -ItemType Directory -Force -Path games/line/src/{core,game,render/skins,ui,net,platform} | Out-Null
New-Item -ItemType Directory -Force -Path games/line/{tools,test,data,out,scripts} | Out-Null
New-Item -ItemType Directory -Force -Path server/{cmd/http,internal/{core,platform/wechat,modules/{profile,leaderboard,friend},games/line},data,migrations,deploy} | Out-Null
```

### 1.4 写 `games/line/package.json`
```json
{
  "name": "line-game",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc --noEmit && vite build",
    "preview": "vite preview",
    "typecheck": "tsc --noEmit",
    "test": "vitest run",
    "test:watch": "vitest",
    "level:gen": "tsx tools/level-gen.ts",
    "level:audit": "tsx tools/batch-audit.ts",
    "level:inspect": "vite --open /tools/level-inspector.html"
  },
  "devDependencies": {
    "typescript": "^5.5.4",
    "vite": "^5.4.0",
    "vitest": "^2.0.5",
    "tsx": "^4.16.2",
    "@types/node": "^22.0.0"
  }
}
```
> **运行时依赖为空** —— 不要引入任何框架。渲染用原生 Canvas 2D。

### 1.5 写 `games/line/tsconfig.json`
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noImplicitReturns": true,
    "noFallthroughCasesInSwitch": true,
    "exactOptionalPropertyTypes": false,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "types": ["node", "vitest/globals"]
  },
  "include": ["src", "tools", "test", "vite.config.ts"]
}
```

### 1.6 写 `games/line/vite.config.ts`
```ts
import { defineConfig } from 'vite';

export default defineConfig({
  server: { port: 5173, host: '0.0.0.0' },
  define: {
    __TARGET__: JSON.stringify(process.env.TARGET ?? 'web'),
    __API_BASE__: JSON.stringify(process.env.API_BASE ?? 'http://127.0.0.1:8080'),
  },
  build: { target: 'es2017', outDir: 'dist', assetsInlineLimit: 0 },
});
```

### 1.7 写 `games/line/src/global.d.ts`
```ts
declare const __TARGET__: 'web' | 'wechat';
declare const __API_BASE__: string;
```

### 1.8 写 `games/line/index.html`

### 1.9 写占位 `games/line/src/main.ts`
```ts
const canvas = document.getElementById('game') as HTMLCanvasElement;
const ctx = canvas.getContext('2d')!;
ctx.fillStyle = '#141824';
ctx.fillRect(0, 0, canvas.width, canvas.height);
console.log('target:', __TARGET__, 'api:', __API_BASE__);
```
> 这是占位，T13 会替换。

### 1.10 写 `games/line/test/smoke.test.ts`
```ts
import { describe, it, expect } from 'vitest';
describe('smoke', () => {
  it('env works', () => { expect(1 + 1).toBe(2); });
});
```

### 1.11 安装依赖并验证
```powershell
cd I:\work\f-game\games\line
npm install
npm run typecheck
npm test
npm run dev
```
> `npm run dev` 应在 http://localhost:5173 打开一个深色空白页，浏览器 console 打出 `target: web api: http://127.0.0.1:8080`。

## 坑
- `npm install` 报 `EPERM` → 终端里执行，或先删 `node_modules` 和 `package-lock.json`
- Vite 端口被占用 → 改 `server.port` 为 5174
- `__TARGET__` 未定义报错 → 确认 `vite.config.ts` 的 `define` 和 `global.d.ts` 都写了

- `games/line/` 可运行工程
- `server/` 目录骨架（空目录即可）
