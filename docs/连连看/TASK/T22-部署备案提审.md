**目标**：部署上线、跑通资质流程、提审通过。**G7 门禁**。

## 步骤

### 22.1 外部流程（**今天就要启动，不要等到这里**）

| 事项 | 周期 | 入口 | 备注 |
|---|---|---|---|
| 域名 ICP 备案 | 1–3 周 | 腾讯云/阿里云备案系统 | 个人主体可备，需身份证 + 手机号 |
| 域名 HTTPS 证书 | 1 小时 | certbot 自动续期 | Let's Encrypt 免费 |
| 软著（软件著作权） | 10–17 天（可加急 3–5 天） | 中国版权保护中心 | 需要：游戏名称、版本号、V3 说明书、源码 60 页 |
| 小游戏备案 | 提审前 | 微信公众平台后台 | 需软著证书 + 备案号 |
| 微信小游戏类目 | — | 后台 | 「休闲益智」类目，一般无需额外资质 |
| 广告位申请 | 提审前 | 微信流量主后台 | 需累计用户达标才可开通，**早期用不了激励视频** |

> **关键提醒**：
> - **广告位**需要账号有足够用户量才能申请（通常要求累计活跃用户数达标）。**冷启动期可能没有激励视频** → 变现策略要准备降级方案（见 22.6）
> - **软著说明书**要写得像正式文档，可以基于 `docs/连连看/10-GDD-连连看.md` 扩写

### 22.2 服务器部署

#### 22.2.1 买服务器
- 腾讯云轻量应用服务器 2C4G，约 60–80 元/月
- 操作系统：Ubuntu 22.04
- 需要**已备案的域名**指向它

#### 22.2.2 初始化
```bash
ssh root@your_server_ip
apt update && apt install -y docker docker-compose-plugin nginx certbot python3-certbot-nginx git
mkdir -p /opt/f-game && cd /opt/f-game
# 上传代码
git clone <your-repo> .
cd server
cp deploy/config.prod.yaml deploy/config.prod.yaml.bak
```

#### 22.2.3 生产配置 `deploy/config.prod.yaml`
```yaml
server:
  port: 8080
  addr: ":8080"
db:
  dsn: "root:STRONG_PASSWORD@tcp(mysql:3306)/fgame?charset=utf8mb4&parseTime=true&multiStatements=true&loc=Local"
redis:
  addr: "redis:6379"
  db: 0
jwt:
  secret: "用 openssl rand -hex 32 生成"
  ttl_hours: 720
wechat:
  appid: "wx真实AppID"
  secret: "真实Secret"
  mock: false
```

#### 22.2.4 docker-compose 加生产环境变量
```yaml
  api:
    build:
      context: ..
      dockerfile: deploy/Dockerfile
    restart: always
    ports:
      - "8080:8080"
    environment:
      DB_DSN: "root:${DB_PASSWORD}@tcp(mysql:3306)/fgame?charset=utf8mb4&parseTime=true&multiStatements=true&loc=Local"
      REDIS_ADDR: "redis:6379"
      JWT_SECRET: "${JWT_SECRET}"
      WECHAT_APPID: "${WECHAT_APPID}"
      WECHAT_SECRET: "${WECHAT_SECRET}"
      WECHAT_MOCK: "false"
```

#### 22.2.5 nginx + HTTPS
```bash
certbot --nginx -d your.domain.com
```

`deploy/nginx.conf`：
```nginx
server {
    listen 80;
    server_name your.domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your.domain.com;

    ssl_certificate     /etc/letsencrypt/live/your.domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your.domain.com/privkey.pem;

    client_max_body_size 2m;

    location / {
        proxy_pass http://api:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

#### 22.2.6 启动
```bash
cd /opt/f-game/server
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml logs -f api
```

**验证**：
```bash
curl https://your.domain.com/healthz
# {"ok":true,...}
```

### 22.3 数据库备份

```bash
# 每天凌晨 3 点备份，保留 7 天
cat > /etc/cron.daily/backup-mysql <<'EOF'
#!/bin/bash
docker exec fgame-mysql-1 mysqldump -uroot -p"$DB_PASSWORD" fgame | gzip > /opt/backups/fgame-$(date +\%F).sql.gz
find /opt/backups -name "fgame-*.sql.gz" -mtime +7 -delete
EOF
chmod +x /etc/cron.daily/backup-mysql
```

### 22.4 软著材料

需要准备：
1. **游戏名称**：如「连连看 - 路径连线」
2. **版本号**：V1.0
3. **说明书**：8–15 页，包含
   - 封面（软件名称、版本号、著作权人、日期）
   - 目录
   - 1. 软件概述（运行环境、功能简介）
   - 2. 操作说明（界面截图 + 操作流程）
   - 3. 功能模块说明（关卡系统、皮肤系统、排行榜、广告系统、分享系统）
   - 4. 技术特点（种子化关卡生成、程序化美术、服务端权威校验）
4. **源码**：前后端源码各 30 页（60 页），每页 ≥ 50 行

**生成说明书**：`docs/连连看/10-GDD-连连看.md` + `14-数值与难度曲线.md` + 截图，可直接扩写。

### 22.6 冷启动期变现降级方案（**重要**）

激励视频在用户量不足时**不可用**（微信流量主要求累计用户达标）。降级策略：

| 阶段 | 变现方式 |
|---|---|
| 0–1000 用户 | **无广告**。用「每日签到送皮肤碎片」维持留存；把广告位代码留着但不触发 |
| 1000–10000 用户 | 申请到激励视频后开启；用「看广告」替代原本的「免费提示」 |
| 10000+ 用户 | 全量开启 + 插屏 + Banner |

**代码层面**：广告不可用时 `ads.showRewarded` 的 catch 已兜底返回 true → 相当于「广告直接略过」，不会卡玩家。**但要避免刷广告次数的收益虚高** → 服务端记录 `adWatchCnt`，只在真实看完时 +1。

## 坑
- **`multiStatements=true` 必须在 DSN 里** → 否则迁移失败
- **JWT_SECRET 用环境变量注入** → 不要提交进仓库
- **微信合法域名必须是 HTTPS + 已备案** → 备案没完成前无法真机联调
- **广告位申请有门槛** → 变现降级方案必须提前准备
- **关卡表改了要重新部署** → 版本号机制会自动让客户端重拉
- **`games/line-wx/dist` 不要提交进 git**（每次构建产物）→ 加 `.gitignore`
