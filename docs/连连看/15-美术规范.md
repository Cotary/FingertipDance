## 2. 纹理实现

| 纹理 | 算法 | 说明 |
|---|---|---|
| none | 纯色 + 顶部线性高光 | 最基础 |

| marble | ValueNoise fbm 脉络 | LCG 洗牌 perm 表，确定性 |
| brushed | 密集水平细线 | 随机 alpha 金属拉丝 |
| ice | 斜向亮线 + 中心菱形 | |

| stardust | 深底 + 闪烁星点 | 依赖 timeMs 闪烁 |
| galaxy | 径向渐变 + 星点 | 依赖 timeMs 闪烁 |

## 3. 调色板派生规则

每个皮肤由 `hue/sat/light` 派生 5 色：`base`（本体）、`light`（+22%）、`dark`（-22%）、`border`（sat+10%, light-32%）、`glow`（sat+15%, light+30%）。

## 4. 渲染约定

- 未点亮砖块：`dark` 色；已点亮砖块：`paintSkin` 真实纹理。
- BLOCK：`dark` 色 + 对角交叉线。
- ONEWAY：`dark` 色 + `glow` 色箭头。
- START/END：固定绿/红圆（不随皮肤变，保证一眼识别）。
- 提示高亮：`#F2C14E` 黄色描边。
- 皮肤预览在皮肤页用真实纹理画 3×3 小棋盘。
