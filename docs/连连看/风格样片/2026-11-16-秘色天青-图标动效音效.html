图标系统

Iconography
机制件不是「功能符号」，是展柜里的一件件器物。三条画法纪律： ① 一器一光（高光恒在左上 27%/19%，投影恒走右下）； ② 釉不过三（釉面渐变 → 扫光高光 → 冰裂/錾刻细线，多一层就脏）； ③ 颜色只从五色族里拿（天青 / 玄墨 / 鎏金 / 朱印 / 暮紫），金色只许出现在箭坯与星屑上。

棋盘格子

Cell Anatomy & Sgraffito
格子是本主题的质感考场——玩家 90% 的注视都落在这里。一颗普通格由五层叠成， 层序固定：釉面渐变 → 冰裂细纹 → 扫光高光 → 划花刻纹 → 光影收口。 非普通格（带机制标 / 石障）底部不叠任何暗纹——冰裂、划花皆不进，净釉面 + 机制标是唯一读点； 冰砖例外，霜裂细纹是它的材质本体。 刻纹用青瓷划花语法：暗刻槽 + 受光边双线，绝不描金（金贵如缮，金色只属于路径与 CTA）。 全格态共 20 式，分三组：路径格（未铺/已铺/起点/终点/起手按下/线头）→ 机关格（石障/单向/星屑三阶/冰砖/钥匙/门开闭/传送门对）→ 反馈态（可连呼吸/提示高亮/抵达爆闪）。

格子解剖 · 五层叠序

从左到右逐层叠加，最右为合成终态。所有层都服从同一束光：左上 35°

立体读法 · 胎厚与台面

左上 35° 单光源 · 棋盘是「凹槽台面」，格子是坐在台面上的瓷片，不是印在板上的色块 · 下方斜置 15° 观察立体关系

刻纹纪律

① 双线立体：暗刻槽在下，受光边 translate(0.5,0.6) 在上
② 只用 round cap / round join，禁锐角飞白
③ 纹样压在冰裂之上、扫光之下——刻进釉里，不贴在釉上
④ 28px 下纹样允许糊成一团质感，但机制图标不允许
⑤ 非普通格净面：带机制标 / 石障的格底部不叠暗纹（冰裂、划花皆不进）；冰砖例外，霜裂是材质本体

格内留白与密度

· 主纹占格面 ≤ 55%，四周留呼吸
· 冰裂 3 组 / 格，多了成脏点
· 深釉格金缘 1px rgba(212,175,106,.22)，辉光 22px 封顶
· 禁：格内文字、数字角标、彩色徽记

动效系统

Motion Language
动效语言只有一个字：釉。所有东西都像釉一样「流下、凝住、描出、落定」。 三个缓动族：釉落 cubic-bezier(.22,1,.36,1) 用于沉淀类｜缮线 cubic-bezier(.4,0,.2,1) 用于绘制类｜ 印顿 cubic-bezier(.22,1.2,.36,1) 用于盖印（唯一允许回弹的地方，回弹 ≤3px）。 点卡片舞台即可重播。

初始界面

Opening Reveal
开局不是「淡入」，是开窑。满盘素坯暗面朝上，像一屉未开的窑； 随后一行行翻面，天青釉面与刻纹次第见光——先盖后揭，暗里藏亮。 翻面顺序可变（行序 / 列序 / 中心旋开），默认行序自上而下：像揭窑巾，读得出节奏。 点舞台可重播揭幕。
点击重播揭幕
盖 · 素坯暗面
FACE-DOWN · BISQUE
背面不是黑块，是未上釉的素坯：玄墨偏褐的陶土面，带极细颗粒噪点与中心一枚指压凹痕。 盖面刻意压掉一切光泽——与翻过来后的乳浊釉形成「暗/亮」的最大反差。同一行内盖面深浅可有 ±4% 随机起伏，避免整排像贴纸。
揭 · 行序翻面
420ms · 釉落 · 45ms 行内错峰
每格绕横轴 rotateX 180° 翻面，420ms 釉落缓动；同一行内从左到右错峰 45ms， 行与行之间停 120ms——一行翻完「落定」，下一行才起。翻到 90° 时翻面高光扫过一次（120ms）， 是釉面见光的那一瞬。
亮 · 见光收尾
末行 · 金光脉冲 + 玉磬
末行落地后整盘金光脉冲一次（420ms，同铺满收尾），玉磬一记（1.4s 尾音自散）， 从此进入可操作态。中途可点按跳过：直接揭完不做缩放弹跳，只留一次金光脉冲。
降级与节奏　reduced-motion 时取消翻面，改「逐行淡亮」（180ms 淡入 + 60ms 行间），保留行序节奏本身； 棋盘大于 12×8 时行内错峰压到 28ms，保证整场揭幕 ≤2.4s——揭幕是仪式，不是等待。 为什么行序　列序像多米诺太「快」，中心旋开太「炫」；行序自上而下像揭一幅卷轴，和「釉落」的沉淀感同轴。

格纹纪律　非普通格（起点/终点/起手按下/线头/单向/星屑/钥匙/门/传送门/石障等带机制标的格）底部不叠任何暗纹—— 冰裂细纹、划花刻纹都不进，机制标是格内唯一读点；暗纹叠在标上会糊住标记，格子就读不清了。 冰砖是唯一例外：霜裂细纹是它的材质本体，不算装饰纹。 普通格（未铺/已铺）照旧走五层叠序：釉面渐变 → 冰裂细纹 → 扫光高光 → 划花刻纹 → 光影收口。
同源双尺寸 · 图标 vs 格内标
常见误用 把 48px 机制图标直接贴进棋格当机关 → 图标细节按 28px 灰度校过，贴格里比例失衡、抢刻纹。
把格内标放大当图鉴插图 → 24px 线稿放大后线宽发虚、经不起细看。
看到格里有梅纹就以为是机关格 → 刻纹是装饰层，机关只认格内标。
在机制格底下垫冰裂 / 划花暗纹 → 叠纹糊标，格子读不清；非普通格一律净面（冰砖例外，霜裂是材质）。
机制图标和格内标混用同一份 SVG → 线宽、留白、光位都不同，必须分两套。
正确用法 图鉴里用 ICONS 48px 大图 + 名称 + 规则文字；棋盘里用 MARKS 24px 小印。
机制格只放一件读点：净釉面 + 一枚格内标；暗纹只活在普通格的五层叠序里，冰砖的霜裂除外。
拿不准时问一句：「玩家现在是在看说明书，还是在看棋盘？」——看说明书给图标，看棋盘给格内标。
新机关入场走三步：先画 48px 图标（过 28px 灰度测试）→ 再出 24px 格内标 → 最后配格态卡。
划花纹样九品已封版；新关卡要新纹样须报备，保持线宽 1.7、留白 ≥40%。
取用顺序　先定 L3 棋格（玩家看得最久）→ 再出 L2 格内标（跟格走）→ 再放大出 L1 图标（跟标走）→ L4/L5 按交互事件挂接。 新增任何资产，先回答「它是哪一层」，再回答「它绝不用在哪」。
