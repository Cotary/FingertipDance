选型军规

Selection Doctrine
RULE 01

灰度可辨

抽掉全部颜色，靠材质/形态/纹理仍能认出是哪套。认不出 = 只是换色板，淘汰。

RULE 02

一轴一世界

每套只占一条语法轴（材质/笔触/结构/时间……）。占两条变特效堆，铁律不破。

RULE 03

原型够硬

必须立在真实顶级工艺传统上（漆器/壁画/珐琅），不是风格标签（像素/赛博）。

RULE 04

明度补位

天青是「暗展柜·冷光」。系列要有极暗场、亮暖场、高饱和彩场，四个世界四张脸。

RULE 05

一金不变

路径金 + 唯一 CTA 金是全系列品牌锚点。主题只换「金的性格」，不换金的存在。

落地排期建议

Build Order
FIRST · 旗舰

02 玄漆螺钿

先做夜场旗舰。理由：①与天青构成日/夜双旗舰，商店页冲击力最大；②深色 + 发光路径是分享图的天然素材（doc 32 原话）；③螺钿虹彩用「同一渐变换相位」实现，程序成本可控。

SECOND · 活动

03 鸣沙丹青

亮暖场，适合逢敦煌/国风活动节点投放。成本主要在颗粒噪点与剥落边缘 mask，渲染管线成熟后最省。可作为「看广告解锁」的首发主题——新世界的感知最强。

THIRD · 收藏

04 掐丝珐琅

彩场收藏位。掐丝的丝格纪律画法最费工（每格双层边），放在管线稳定后做。它是「主题商店」的压轴：工艺感最满，适合做付费/成就向的高级奖励。

落选说明 · 为什么不是另外几个

水墨飞白——与已上线「水墨山河」同占媒介轴，灰度下都是"亮纸+墨块"，是换皮不是换世界。若将来重做水墨，须改轴（如「手卷装裱」：棋盘是一卷展开的手卷）。 金缮瓷盘——与天青同属瓷面材质，灰度下孪生兄弟，只配做天青的变体（盘面开片样式）而非独立主题。 像素街机 / 赛博霓虹——已被否：风格标签不是工艺传统，撑不起「高级」，也没法做真实的材质通道。

不变的红线（四套共守，doc 32）：路径与格子色相差 ≥120° 或明度差 ≥35%｜已铺/未铺明度差 ≥8%｜机制图标 28px 灰度剪影可辨｜金色覆盖 ≤8%｜光源永远左上 35°｜触感与声音同帧 ≤50ms。
