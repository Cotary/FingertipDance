图标系统

Iconography
图标不是画出来的「图案」，是从壁面上剥下来的色块。三条画法纪律： ① 每个图标都有缺口（剥蚀，不能是完美几何形）； ② 表面必须有矿物颗粒（feTurbulence 噪点 ≥0.35 透明度）； ③ 颜色从矿物色族里拿（赭石/朱砂/石绿/石青/土红/沥金），不发明新色。

棋盘格子

Cell States
格子是从壁面上剥下来的一片片色块——歪斜、带缺口、有颗粒，绝不是完美圆角矩形。 全格态共 20 式，分三组：路径格（未铺/已铺/起点/终点/起手按下/线头）→ 机关格（石障/单向/星屑三阶/冰砖/钥匙/门开闭/传送门对）→ 反馈态（可连呼吸/提示高亮/抵达爆闪）。 起点用朱砂印，终点与路径用沥金，机关色只从矿物色族里拿。

动效系统

Motion Language
动效语言只有一个字：沙。所有东西都像沙一样「落下、堆起、扬起、沉淀」。 三个缓动族：沙落 cubic-bezier(.22,1,.36,1) 用于沉淀类｜沥线 cubic-bezier(.4,0,.2,1) 用于绘制类｜ 石顿 cubic-bezier(.34,1.56,.64,1) 用于砸击类（唯一允许回弹的地方）。点卡片舞台即可重播。

初始界面

Opening Entrance
开局不是淡入，是落壁：棋盘先空着，壁面上只留一排排凹进去的格槽。 色块像从壁面剥下又贴回去的残片，一行一行从上落到棋盘上——行序自上而下，行内左→右 30ms 错峰， 触底压扁沉回、沙尘向右下扬出、泥点落一记。最后一行落定，全盘沙光脉冲 + 土埙一记，转入可操作态。 载入自动播一遍；点舞台重播；动画中再点 = 跳过（全部直接落定）。

落 · 行序落壁
Rows Drop In
行序自上而下（上行先落，像残片从壁顶贴下来），行内左→右 30ms 错峰。
每格坠落 420ms（重力段加速 cubic-bezier(.45,0,.8,.35)，触底段沙落沉降），行间 220ms，整盘 ≤ 1.7s。
入场是仪式不是等待：大盘 >12×8 时错峰压到 18ms，总时长封顶 2.4s。
尘 · 触底扬尘
Dust On Landing
触底帧块体压扁 8% 再沉回原位——压扁是沉降，不是石顿回弹（回弹只属于盖印）。
每 3 格一撮：3 粒沙尘向右下 35° 扬出（与光源同向，复用落子的扬尘语言）。
每格触底一记泥点落（vol 0.22 低语量），行落定有 6ms 轻震。
亮 · 沙光收尾
Sand-Glow Finish
末行落定，全盘沙光脉冲 420ms（暖金从盘底漫起）+ 土埙一记，转入可操作态。
动画中点击舞台 = 跳过：所有格直接落定、沙光照播，不回放过程。
prefers-reduced-motion 降级：不做坠落，逐行淡亮 180ms + 60ms 行间，保留行序节奏。

格纹纪律　非普通格（起点/终点/起手按下/线头/单向/星屑/钥匙/门/传送门/石障等带机制标的格）底部不叠任何装饰纹—— 六字纹样不进机制格，机制标是格内唯一读点；纹样叠在标上会糊住标记，格子就读不清了。 材质纹理例外：矿物颗粒、冰砖的石青晶面、传送门的深靛漩底是材质本体，不算装饰纹。 六字纹样只活在普通格（未铺/已铺）的色块上。
同源双尺寸 · 图标 vs 格内标
常见误用 把 48px 机制图标直接贴进棋格当机关 → 图标细节按 28px 灰度校过，贴格里比例失衡、抢纹样。
把格内标放大当图鉴插图 → 24px 线稿放大后笔触发虚、经不起细看。
看到格里有月纹就以为是机关格 → 纹样是装饰层，机关只认格内标。
在机制格底下垫六字纹样 → 叠纹糊标，格子读不清；非普通格一律净面（材质纹理除外）。
传送门做成石绿 → 和石绿格融为一体（此病已治：深靛漩底 + 石青环 + 沥金芯）。
正确用法 图鉴里用 ICONS 48px 大图 + 名称 + 规则文字；棋盘里用 MARKS 24px 小印。
机制格只放一件读点：净色块 + 一枚格内标；六字纹样只活在普通格上。
拿不准时问一句：「玩家现在是在看说明书，还是在看棋盘？」——看说明书给图标，看棋盘给格内标。
新机关入场走三步：先画 48px 图标（过 28px 灰度测试）→ 再出 24px 格内标 → 最后配格态卡。
机关色只从矿物色族拿；新纹样须报备，保持剥蚀缺口、不做完美几何形。
取用顺序　先定 L3 棋格（玩家看得最久）→ 再出 L2 格内标（跟格走）→ 再放大出 L1 图标（跟标走）→ L4/L5 按交互事件挂接。 新增任何资产，先回答「它是哪一层」，再回答「它绝不用在哪」。
