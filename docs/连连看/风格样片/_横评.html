连连看 · UI 风格 三选一

三套都换的是材质语言，不是配色。样片为方向示意（AI 生成），最终实现由 Canvas 代码绘制。 右下的「落地度」是这套风格在 Canvas2D 里能还原到几成 —— 这个比图片好不好看更决定最终效果。

A · 剪纸星球Paper Planet
所有元素是「剪下来贴上去的纸片」，靠硬投影叠出层数。米黄纸底，粗墨描边，小圆角。
落地度★★★★★ ★
记忆点撕边 + 硬投影，一眼是「手工做的」
风险浅底在强光下不如深底醒目；配色偏自然复古
B · 三色油印Riso Press
只准三种油墨印在米白纸上，45° 网点 + 3px 套印错位，全部图形统一黑描边。
落地度★★★★ ★
记忆点套印错位 —— 没有一个连连看这么做
风险文字压网点可读性差；只有 4 色，功能色难区分
C · 黏土工坊Clay Studio
橡皮泥捏的定格动画一帧。硬边色块代替渐变，带指纹与压痕。
落地度★★ ★★★
记忆点手工捏制的不规则轮廓，质感最贵
风险指纹/柔光 Canvas 做不了，会掉回「果冻」观感
为什么推荐 A：卡通感来自造型和描边，不来自配色。剪纸风天生有粗描边、小圆角、不规则轮廓 —— 这是卡通的骨架； 硬投影让每个元素真的浮在下一层，不需要发光就有层次（发光正是廉价的层次替代品）。 而它 95% 能用 Canvas 画出来，不会「设计稿好看、做出来是另一回事」。
C 的问题：样片的那种指纹纹理和棚拍光照需要法线贴图或 3D 渲染，Canvas 只能做到「圆润渐变 + 硬阴影」—— 最终会退回现在这套被否掉的果冻感。除非上 3D 预渲染位图，那又是包体和加载的代价。
深色怎么办：A 有一个「皮影」变体 —— 同一套造型，底换成深蓝纸 #1D2B4F，纸片改成透光暖黄，投影几乎全黑。 只换色板，不动结构，等于一个方向覆盖明暗两版。
