链路说明
四段闭环 从「通关」到「再来一局」，中间不许断
分享挑战不是一个按钮，是一条完整闭环：通关 → 分享 → 好友同关 → 比重来。 本稿把此前只有信息条的「分享挑战」展开成可点可用的整条链路， 口径与实现（challenge.ts / share.ts / 18-社交裂变设计.md）逐字对齐，不发明新功能。
壹 · 通关落印 结算页点「分享」——成绩就是关卡号 + 重来次数，星级同源（0 重来 = ★★★）
→
贰 · 海报出窑 程序化渲染 750×1334 海报 + 文案池随机一条；链接带 l / undos / uid / name
→
叁 · 好友应战 点开直达第 N 关，不经过大厅；盘上横幅「X 的挑战」；不推进我的主线
→
肆 · 以印定音 我的重来 ≤ 他的重来 = 胜（平手算赢）；胜落「胜」印，惜败不落印

分享 · 只带两样

步数 / 分数 / 道具（虚构） → 只带关卡号 + 重来数（undos）。cover 模式步数恒为 required−1，没有区分度；重来次数才是成绩，也是星级的口径。

入口 · 直达同关

好友点开 parseChallenge 命中即进第 N 关，不经过大厅、不弹前置页。横幅只说一件事：「谁的挑战 · 第几关」，目标写在横幅右侧。

判定 · 平手算赢

对比维度是双方重来次数（优先跟分享链接里那位好友比，不是跟全服最佳比）。我 ≤ 他即胜——「跟好友一样好」也是赢。挑战成绩不推进主线。

印 · 落与不落

通关落「过」，挑战成功落「胜」，惜败不落印——朱印是通关与胜利的专利。惜败只给石色圆章「惜」，无回弹、无欢呼，重量来自克制。

埋点四枚：share_click / share_success / challenge_start / challenge_result（18-社交裂变设计.md 已落盘）。 海报零图片素材、纯程序化 canvas，取色随当前主题六通道——天青与丹青同构图换肤（见海报定稿）。 裂变健康度：分享率 > 5% · 点击→首局完成 > 50%。
