# 06 — 微信小游戏移植规格

> T21 的执行依据。**当前阶段只需阅读"红线"部分。**

---

## 1. 微信小游戏工程红线

| # | 红线 | 说明 |
|---|---|---|
| 1 | **无 DOM/BOM** | `document` / `window` / `localStorage` 都不存在。全部 Canvas 绘制 + `wx.*` API |
| 2 | **无 DOM 事件** | 用 `wx.onTouchStart/Move/End` 代替 `addEventListener` |
| 3 | **无 CSS** | 样式全部在 Canvas 里画。禁止任何 `.css` 文件 |
| 4 | **首包 ≤ 4MB** | 主包只放代码 + 必要 JSON；关卡表**不要**打进包（从后端拉） |
| 5 | **必须 HTTPS** | `wx.request` 的合法域名必须是 **HTTPS + 已 ICP 备案**的域名 |
| 6 | **登录** | `wx.login()` → `code` → 发给后端 → 后端 `code2session` |
| 7 | **开放数据域** | 好友榜需要独立子目录 `openDataContext/`，用 `wx.getOpenDataContext()` |
| 8 | **后台销毁** | 小游戏切后台会被销毁 → 进度必须落服务端或本地持久化 |
| 9 | **分享不检测结果** | 微信已管控分享接口，**不要**用"必须分享成功才给奖励"的逻辑 |
| 10 | **支付** | 本期纯 IAA，**不接支付**（个人主体拿不到版号） |

## 1.1 微信端 vs Web 端差异表

| 能力 | Web（开发/试玩） | 微信 |
|---|---|---|
| Canvas 创建 | `document.createElement('canvas')` | `wx.createCanvas()` |
| 触摸 | `pointerdown/move/up` | `wx.onTouchStart/Move/End` |
| 存储 | `localStorage` | `wx.setStorageSync` / `wx.getStorageSync` |
| 网络 | `fetch` | `wx.request` |
| 登录 | mock | `wx.login()` |
| 广告 | mock（假倒计时） | `wx.createRewardedVideoAd` 等 |
| 分享 | `navigator.share` / 复制链接 | `wx.shareAppMessage` |
| 排行榜 | 服务端接口 | 开放数据域 + 服务端 |
| 画布离屏 | `document.createElement('canvas')` | `wx.createOffscreenCanvas` 或 `wx.createCanvas()` |

## 2. 适配层设计（`src/platform/`）

```
src/platform/index.ts     # 导出当前平台实现（构建时按 TARGET 切换）
src/platform/web.ts       # Web 实现（mock）
src/platform/wechat.ts    # 微信实现
```

**接口定义（`index.ts`）**：
```ts
export interface Platform {
  readonly name: 'web' | 'wechat';
  login(): Promise<{ code: string }>;
  request<T>(url: string, method: 'GET'|'POST', data?: any, header?: Record<string,string>): Promise<T>;
  storage: {
    get(key: string): string | null;
    set(key: string, value: string): void;
    remove(key: string): void;
  };
  ad: {
    showRewarded(placement: string): Promise<boolean>;   // true = 完整看完
    showInterstitial(placement: string): Promise<void>;
    showBanner(): void;
    hideBanner(): void;
  };
  share(opts: { title: string; imageUrl?: string; query?: string }): Promise<void>;
  vibrate(): void;
  getCanvas(): { canvas: HTMLCanvasElement; width: number; height: number; dpr: number };
  openData: { available: boolean };
}
```

**`platform/index.ts` 的切换方式**：
```ts
export const platform: Platform = __TARGET__ === 'wechat' ? wechatPlatform : webPlatform;
```
构建用 Vite 的 `define` 注入 `__TARGET__`。

**铁律**：`src/` 下除 `platform/wechat.ts` 外，**任何文件不得出现 `wx.` 字面量**。

## 3. 微信工程目录

```
games/line-wx/
├─ game.js               # 入口，加载适配层与主逻辑
├─ game.json              # {"deviceOrientation":"portrait"}
├─ project.config.json
├─ project.private.config.json
└─ openDataContext/
   └─ index.js            # 好友榜渲染（独立 JS 环境，只能用 wx API）
```

**注意**
- 微信小游戏**没有 `index.html`**，入口是 `game.js`
- 开放数据域的 JS 是**完全独立**的运行环境，不能访问主域变量 → 好友榜的绘制逻辑要单独写一份（或从主域复制）
- 主域 → 开放数据域的数据传递：`wx.setUserCloudStorage`（主域写）+ `wx.getFriendCloudStorage`（开放数据域读）

## 4. 开放数据域好友榜（T19）

### 4.1 主域写入
```ts
wx.setUserCloudStorage({
  KVDataList: [{ key: 'line_profile', value: JSON.stringify({
    maxLevel, totalTimeMs, totalSteps, skinCount, nickname, avatar, updatedAt
  })}],
  fail: console.warn
});
```

### 4.2 开放数据域读取并绘制
```js
// openDataContext/index.js
const { sharedCanvas, wx } = wx.getOpenDataContext();
const { ctx } = sharedCanvas;
// ... 绘制好友榜到 sharedCanvas
```

### 4.3 主域渲染开放数据域 canvas
```ts
const odCanvas = wx.getOpenDataContext().canvas;
ctx.drawImage(odCanvas, x, y, w, h);
```

### 4.4 坑
- 开放数据域**刷新是异步的**，好友榜数据不会立刻更新 → UI 上要显示"刷新中"
- 开放数据域不能直接访问 `wx.getFriendCloudStorage` 之外的好友信息（只有玩家自己授权的好友）
- **好友榜数值必须用服务端同款公式**，否则两边显示不一致 → 共享一个 `computeRankScore()` 函数（在 `core/` 下，两端都能引）

## 5. 分享挑战（T20）

### 5.1 分享时的 query
```ts
wx.shareAppMessage({
  title: `我卡在第 ${levelIdx} 关，你能连过去吗？`,
  imageUrl: posterTempFilePath,
  query: `l=${levelIdx}&s=${seed}&uid=${uid}`,
});
```
- `seed` 可省（关卡统一，靠 `levelIdx` 即可），保留是为了将来支持"自定义关卡"

### 5.2 好友进入时
- 启动参数 `query` → 解析出 `l`（关卡号）
- 优先进入被挑战的关卡（**即使玩家还没到那一关**）→ 体验更好
- 挑战模式 UI：顶部显示"好友的挑战"，结算显示"你赢了/输了"
- 成绩走 `POST /api/challenge`（不影响主线进度）

## 6. 广告 API 具体用法

### 6.1 激励视频
```ts
const ad = wx.createRewardedVideoAd({ adUnitId: 'adunit-xxx' });
ad.onClose((res) => { /* res.isEnded 判断是否完整看完 */ });
ad.onError((err) => { /* 兜底发放 */ });
ad.load().then(() => ad.show()).catch(() => ad.load().then(() => ad.show()));
```

### 6.2 插屏
```ts
const ad = wx.createInterstitialAd({ adUnitId: 'adunit-yyy' });
ad.onClose(() => {});
ad.load().then(() => ad.show()).catch(() => {});   // 失败静默
```

### 6.3 Banner
```ts
const ad = wx.createBannerAd({ adUnitId: 'adunit-zzz', style: { left: 0, top: 0, width: 750 } });
```

## 7. 迁移检查清单

- [ ] 所有 UI 在 Canvas 上重画（Web 版的 DOM 元素全部去掉）
- [ ] `document` / `window` / `localStorage` / `addEventListener` 全部替换
- [ ] `fetch` → `wx.request`（注意 `wx.request` 不支持 `Promise` 语法糖，必须包一层）
- [ ] 画布尺寸用 `wx.getSystemInfoSync().windowWidth/windowHeight` + `pixelRatio`
- [ ] 关卡表**从后端拉**，不打进包
- [ ] `game.json` 设为竖屏
- [ ] 合法域名已在微信后台配置
- [ ] 开放数据域子目录已配置
- [ ] 广告位 ID 已申请并在后台配置
- [ ] 提审素材：图标 512×512、截图 3–5 张（微信要求竖屏 1242×2208 之类）
- [ ] 隐私协议页面（收集 openid 需说明）

## 8. 上线前外部流程（**有周期，需最早启动**）
| 事项 | 周期 | 谁做 |
|---|---|---|
| 域名 ICP 备案 | 1–3 周 | 你（个人主体可备） |
| 软著（软件著作权） | 10–17 天 | 可加急，需游戏名称 + 版本 + 说明文档 |
| 小游戏备案 | 提审前 | 需软著 + 备案号 |
| 微信小游戏类目资质 | 休闲益智类 | 一般无需额外资质 |
| 广告位申请 | 提审前 | 微信后台 |

> **这些都要在 T22 之前启动**，不要等到最后一周。
