# 37 · IP 级主题包设计（四套）

> 触发：「不是现在那四个风格主题，我要冰雪奇缘、马里奥那种有 IP 感的」。
> 结论：**不仿制 IP，做同气质的原创主题包**——玩家读到的是「冰晶王国」，不是「艾莎」。
>
> 本文是四套的**可施工规格**：色板、几何、图标、音效、解锁点、以及每套与现有主题的
> 「差异化声明」（一份设计文档里最容易缺、也最容易导致两套主题撞车的一节）。

---

## 一、先说清楚：为什么不能直接做冰雪奇缘 / 马里奥

| 项 | 冰雪奇缘 | 马里奥 |
|---|---|---|
| 权利方 | Disney | Nintendo |
| 受保护对象 | 角色形象、雪花符号体系、配色组合、音乐 | 角色、砖块/水管/金币的具体造型、音效 |
| 商用要求 | 授权（保底金 + 分成，周期以月计） | 授权（任天堂对游戏授权极谨慎） |
| 不授权的后果 | 微信/抖音小游戏审核判「实质性相似」→ 驳回、已上线则下架封号 | 同左 |

「改个颜色 / 换个名字」不构成规避：判定看的是**标志性元素的可识别性**，
不是色值。所以这里只做**同气质原创**——所有形状、命名、音效都重新设计，
只在「情绪」这一层对标。

## 二、现有八套已经占了哪些轴（新主题必须避开）

`themes/index.ts` 的规矩是：**一套主题只换一条语法轴**，占两条就变「特效堆」。

| 已上线 | 轴 | 换掉了什么 |
|---|---|---|
| 水墨山河 `ink` | 媒介 | 深色发光 → 亮纸墨块 |
| 玻璃穹顶 `glass` | 材质 | 实心块 → 透光块 |
| 圆格罗盘 `orbit` | 几何 | 方格 → 圆心 |
| 像素街机 `pixel` | 分辨率 | 连续边缘 → 硬像素 + 扫描线 |
| 赛博霓虹 `neon` | 平面 | 有面 → 只有发光框 |
| 黑曜熔岩 `obsidian` | 光源 | 外照光 → 自发光 |
| 金线装饰 `gilded` | 秩序 | 色块 → 只有线 |
| 深海荧光 `abyss` | 形态 | 直边 → 只有软体 |

新四套各挑一条**没被占的**：

| 新主题 | 轴 | 为什么不会和上面撞 |
|---|---|---|
| ~~冰晶王国 `frost`~~ | ~~晶体几何（六边冰晶 + 裂纹）~~ | glass 是圆角**方**玻璃；这里是**六边**晶体。灰度下一个是方格网、一个是冰晶阵列 |
| 砖块水管世界 `bricks` | **物件语法**（砖 / 管 / 币） | pixel 换的是「分辨率」（整屏低清 + 扫描线）；这里分辨率正常，换的是「东西长什么样」 |
| 深海亚特兰蒂斯 `atlantis` | **遗迹建筑**（石板 + 光柱） | abyss 没有一条直边、纯生物发光；这里是直线石板、有墙有柱 |
| 森林精灵 `forest` | **生长**（藤蔓 / 苔藓毛边） | ink 是硬边墨块留白；这里是圆润毛边 + 暖绿，线是「活的」 |

## 三、四套规格

### 3.1 冰晶王国 `frost` · 晶体几何轴（**已落地**）

**一句话**：整张棋盘是一座冻住的湖，每一格是一块六边冰晶。

| 通道 | 规格 |
|---|---|
| 背景 | 深蓝夜空 `#040B18 → #0A1B33 → #123049`；两条**极光带**（`#5BE8C8` 绿 / `#9B7BFF` 紫，沿 sin 波上下浮动，alpha 0.10~0.18）；极细星点；底部一道雪脊白边 |
| 底板 | 半透明冰面 `rgba(198,232,255,0.08)`，顶缘一条白亮线（0.35），内部 3 团冻住的气泡（小圆，alpha 0.12） |
| 格（未走） | **正六边形**（pointy-top），内缩 8%，边长 `cell*0.46`（方阵里无法密铺，见 §3.1 注）；描边 `rgba(214,240,255,0.34)`，宽 `cell*0.030`；不填色 |
| 格（走过） | 填 `rgba(214,242,255,0.42)` + 内高光 `rgba(255,255,255,0.20)`；描边提到 0.85；画**一条折线裂纹**（从格心到边缘，两段折线），颜色 `rgba(255,255,255,0.55)` |
| `BLOCK` 冰崖 | 填 `#0C2138`，左上斜切高光 `rgba(160,220,255,0.26)`，右下暗边 `#05101E`，一条贯穿裂纹 |
| `ICE` 冰砖 | 普通格 + **第二圈虚线内环**（`rgba(255,255,255,0.45)`，dash `[3,4]`）+ 中心六角霜花。比普通格亮 15%——这是 doc 32 的硬规矩（ICE 必须更亮/更透/有裂纹，三条占两条） |
| 路线 | **雪橇辙**：两条平行白线（间距 `cell*0.16`，宽 `cell*0.05`）+ 中间雪粒点（每 1.6 格一个，半径 `cell*0.03`）；色 `#CFF0FF` |
| 图标 | 复用 `ice` 笔触（冰体 + 白霜），pal `ink #EAF7FF / accent #7FD8FF / chip #FFFFFF / deep #0A1B33` |
| 起点 / 终点 | 起点 = 冰洞（深色圆 + 内圈白霜边）；终点 = 冰晶柱（六边形 + 四道星芒） |
| 提示 | 六边形描边，`#FFE9A8`，宽 `cell*0.075`（第一格）/ `0.045`（其余） |
| 界面 | pill `#12314D`/`#EAF6FF`；primary `#2A6E9E`/`#F2FBFF`；ghost `#173A57`/`#CFEBFF`；groove `rgba(127,216,255,0.18)`；fill `#7FD8FF` |
| 音效 | 落子 = 敲冰（短促 1.8kHz + 80ms 尾音）；滑行 = 低频摩擦（200Hz 噪声，随速度调制） |
| 解锁 | 第 300 关 |
| 地图联动 | `mapstyle.ts` 加 `frost`：夜 `#04101F → #0B2540`，路 `#7FD8FF`，星 `#DFF6FF`，世界色往冰蓝混 |

> **⚠️ `frost` 已下线（2026-11-14）。** 它不是「参数没调好」，是方向错了：
> 只要格子还是「画个框」，换成什么形状都只是另一种网格。替代品 `kintsugi`「金缮瓷盘」
> 改从**材质**下手 —— 完整复盘见 `38-金缮瓷盘.md`。

> **注：为什么不是真蜂窝。** 真实蜂窝要奇偶行错位半格，而棋盘是严格方阵（`layout.cell` 等距），
> 错位就不是同一套布局了。所以这套的做法是「一颗颗独立的六边冰晶嵌在冰面上，缝隙留给霜」——
> 灰度下它仍然和玻璃的方格网完全不同，但宣传语里不许写「蜂窝」。

### 3.2 砖块水管世界 `bricks` · 物件语法轴

**一句话**：格子是砖，挡路是问号块，传送门是绿水管——但一个角色都不出现。

| 通道 | 规格 |
|---|---|
| 背景 | 经典天空蓝 `#5C94FC → #8FC0FF`（**唯一的亮色主题之二**，和 ink 并列）；三朵像素云（白，圆角三次贝塞尔）；地面一条 32px 草边 + 土层 |
| 底板 | 深棕木框 `#6B3A18`，内描边 `#3E1F0C`，四角铆钉 |
| 格（未走） | **砖**：`#C84C0C` 底 + 两行错缝砖纹（缝 `#7A2E05`，宽 2）+ 顶边高光 `#E07A33`；砖缝相位按 `(gx + gy) % 2` 错开 |
| 格（走过） | 砖被敲过：亮一档 `#E07A33` + 四角小钉（白点）+ 轻微内凹暗边 |
| `BLOCK` 问号块 | `#E8A020` 底 + `#7A4A00` 描边 + 中央 `?`（`pixel` 笔触）+ 四角铆钉；**未敲时轻微呼吸**（alpha 0.85~1.0） |
| `ICE` 冰砖 | 浅蓝砖 `#8FD4FF` + 白斜纹；比普通砖亮，且砖缝更细 |
| 路线 | 像素折线：`miter` + `butt`，宽 `cell*0.16`，色 `#FFF3C4`（不是纯白，纯白在蓝天上会发光过度） |
| 图标 | 复用 `pixel` 笔触，pal `ink #FFF6D8 / accent #FFD447 / chip #FFFFFF / deep #2A1503` |
| 起点 / 终点 | 起点 = 圆形井盖（灰圈 + 十字）；终点 = 旗杆（杆 + 三角旗） |
| 提示 | 黄色方框（圆角 2），宽 `cell*0.08` |
| 界面 | pill `#2A4A8A`/`#FFF3C4`；primary `#C84C0C`/`#FFF6E0`；ghost `#1F3A6E`/`#CFE2FF` |
| 音效 | 砖块敲击（方波 220Hz，40ms）；金币（两个上行方波） |
| 解锁 | 第 500 关；**风险**：任天堂对「砖 + 问号块 + 水管」组合的观感极敏感，配色必须偏离原作（改暖橙、改木框），且绝不出现角色/蘑菇 |

### 3.3 深海亚特兰蒂斯 `atlantis` · 遗迹建筑轴

**一句话**：沉在海底的石头城，格子是被珊瑚包住的石板。

| 通道 | 规格 |
|---|---|
| 背景 | `#02141C → #04222E → #062E3A`；三道**光柱**（从顶部斜插，`rgba(180,255,240,0.08)`，宽 90/140/70）；悬浮微粒（24 颗，缓慢上升） |
| 底板 | 石板平台 `#1E3A38`，边缘被珊瑚啃过的**不规则圆角**（每边中点内凹 3px），底部沉沙渐变 |
| 格（未走） | 石板：圆角 0.18，填 `#243F3C`，单边**缺口**（按 `idx%4` 选一边，宽 `cell*0.18`），描边 `rgba(120,190,170,0.20)` |
| 格（走过） | 长满青苔：填 `#2F5A48` + 苔点（5 个 `#4FA86A` 小圆，位置由 `idx` 决定）+ 缝隙发光 `rgba(120,255,210,0.22)` |
| `BLOCK` 断墙 | 双层石块（上下两块，错缝）+ 珊瑚枝（2 条曲线，`#E86A6A`） |
| `ICE` 水潭 | 填 `rgba(80,200,220,0.18)` + 水面反光弧（两条白弧）+ 上升气泡（3 个） |
| 路线 | 水流：三段描边（`rgba(20,80,90,0.6)` 宽 / `#6FE8D0` 中 / `#E8FFF8` 细），沿路径每 2 格一个气泡 |
| 图标 | 需新增 `stone` 笔触（厚衬线 + 凿痕，`lineCap='butt'`，每笔末端加一个 1px 的凿点） |
| 起点 / 终点 | 起点 = 海螺（螺旋两圈）；终点 = 三叉戟（三竖 + 一横） |
| 提示 | 圆角石框 + 内侧发光，`#FFE9A8` |
| 界面 | pill `#0F2E32`/`#D8FFF4`；primary `#1E6E6A`/`#EAFFFA`；ghost `#16403E`/`#A8E8DA` |
| 音效 | 水泡（上行正弦扫频）；石门开启（低频 + 砂砾） |
| 解锁 | 第 800 关 |

### 3.4 森林精灵 `forest` · 生长轴

**一句话**：棋盘长在森林里，格是苔藓地，路是藤蔓。

| 通道 | 规格 |
|---|---|
| 背景 | `#0B1A10 → #13291A`；四簇**树冠剪影**（深绿，圆润三段弧）；叶隙光斑（6 团 `rgba(255,240,180,0.10)`，缓慢明灭）；萤火虫 12 只（黄绿点 + 尾迹） |
| 底板 | 苔藓地：`#1B3320` + 边缘毛边（每 24px 一个 1.5px 的随机凸起） |
| 格（未走） | 圆角石块 `radius 0.22`，填 `#2A4630`，描边 `rgba(140,200,120,0.22)`；四角各一撮草（2px 短线） |
| 格（走过） | 草长出来：填 `#3A6B3C` + 5 根草叶（贝塞尔，随 `now` 轻摆 ±4°）+ 一朵小花（每 7 格一朵，`#F2C86A`） |
| `BLOCK` 树桩 | 树桩：同心圆 3 圈（年轮）+ 顶部苔藓边 + 一根新芽 |
| `ICE` 溪水 | 填 `rgba(110,200,220,0.16)` + 两道水波弧 + 一颗露珠高光 |
| 路线 | 藤蔓：`#7FC24A` 主蔓（宽 `cell*0.10`）+ 深绿描边 + 每 1.5 格一片叶（两段贝塞尔）；叶随 `now` 微摆 |
| 图标 | 需新增 `leaf` 笔触（单线叶脉，软头，末端回勾） |
| 起点 / 终点 | 起点 = 树洞（椭圆 + 内暗）；终点 = 蘑菇圈（三朵小蘑菇） |
| 提示 | 叶形描边（两段贝塞尔围成的橄榄形），`#FFE9A8` |
| 界面 | pill `#1E3A22`/`#EAF6D8`；primary `#4E7A3A`/`#F6FFE8`；ghost `#274A2C`/`#CFE8B8` |
| 音效 | 脚步声（低频软噪声）；萤火虫（极轻的高频铃） |
| 解锁 | 第 1000 关（跑完全程的最终奖励） |

## 四、制作成本与顺序

| 项 | 每套成本 | 说明 |
|---|---|---|
| 渲染器（backdrop/plate/cell/trail/endpoint/hint） | 200~260 行 | 用 `composeTheme` + `ThemeKit`，不必碰主循环 |
| 新图标笔触（如需） | 60~100 行 | `atlantis` 需 `stone`，`forest` 需 `leaf`；另两套复用 `ice` / `pixel` |
| 四处注册 | ~20 行 | `themes/index.ts`、`mapstyle.ts`、商店文案、测试 |
| 音效 | 2 个 wav | 走 `render/audio.ts` 的现有通道 |

顺序建议（先做**差异最大、复用最多**的）：

1. `frost`（复用 `ice` 笔触，只做几何 → 最快见效）✅ 已完成
2. `forest`（新增 `leaf` 笔触，验证「线是活的」）
3. `atlantis`（新增 `stone` 笔触，验证光柱/水下氛围）
4. `bricks`（复用 `pixel`，但法务最敏感，放最后并做观感偏离评审）
