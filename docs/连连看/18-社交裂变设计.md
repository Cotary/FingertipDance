# 社交裂变设计（实现落盘）

> 本文件是 T20「分享挑战」的设计与实现落盘。

## 1. 分享漏斗埋点

| 埋点 | 触发点 | 位置 |
|---|---|---|
| `share_click` | 点「分享」 | `src/main.ts` `doShare()` |
| `share_success` | 分享成功回调 | 预留（`platform.share` 成功分支） |
| `challenge_start` | 好友通过分享进入（`parseChallenge` 命中） | 预留（`boot()` 命中挑战时） |
| `challenge_result` | 挑战通关结算 | `src/main.ts` `onChallengeWin()` |

## 2. 挑战模式完整链路

```
好友 A 通关第 N 关 → 点「分享」→ renderPoster 生成海报(750×1334)
  → platform.share({ title, query: "l=N&steps=M" })
好友 B 点开 → parseChallenge() 读 query → 进入第 N 关
  → 顶部横幅「A 的挑战 · 第 N 关」
  → B 通关 → onChallengeWin → POST /api/challenge（不推进主线）
  → 结算面板「挑战成功/惜败 + 我的步数 vs 最佳步数」
```

## 3. 分享文案池

`src/ui/share.ts` 的 `COPY_POOL`（4 条，`Math.random()` 随机）：

- 我卡在第 {lv} 关，你能连过去吗？
- 这关我用了 {steps} 步，你呢？
- 敢不敢试试我的皮肤？
- 第 {lv} 关，我不信你过得去

测试方法：A/B 测分享率，替换表现最差的文案。

## 4. 好友榜（开放数据域）与服务端好友的关系

| 数据源 | 用途 | 说明 |
|---|---|---|
| 开放数据域 `wx.getFriendCloudStorage` | 好友榜排名 | 只返回互为好友的用户，免后端 |
| 服务端 `/api/friends` | 好友进度统计面板 | 好友数/平均进度/最高进度/我的名次 |

两者可能不一致：开放数据域画榜，服务端算统计，各司其职。

## 5. 裂变健康度指标

- 分享率 > 5%
- 点击 → 首局完成转化率 > 50%

## 6. 实现位置

- `src/game/challenge.ts` — `parseChallenge`/`buildShareQuery`
- `src/net/api.ts` — `reportChallenge`
- `src/ui/share.ts` — `renderPoster`/`shareCopy`（平台分支离屏 canvas）
- `src/main.ts` — 挑战模式接入（横幅/结算/分享/重试）
- `test/challenge.test.ts` — 2 用例
