## 1. 软件概述

### 1.1 运行环境
- 客户端：微信小游戏（iOS/Android 微信内运行）
- 服务端：Go + MySQL + Redis，Docker 部署
- 编程语言：TypeScript（客户端）、Go（服务端）

### 1.2 功能简介
本软件是一款「路径连线」休闲益智小游戏。玩家从起点按住屏幕，沿上下左右相邻格拖动到终点，路过的格子被点亮，不能经过阻挡块、不能断线、不能原路退回。包含 1000+ 关卡、16 种皮肤、排行榜、好友榜、分享挑战、激励视频等系统。

## 2. 操作说明

1. 打开游戏进入当前关卡
2. 按住绿色起点，拖动连线到红色终点
3. 松手即判定：连线完整则通关，进入结算页
4. 可点「提示」查看下一步、「跳过」跳过关卡
5. 通关解锁皮肤，可进皮肤页装备
6. 可分享关卡挑战好友、查看好友榜

## 4. 技术特点

1. **种子化关卡生成**：mulberry32 伪随机 + FNV-1a 哈希，同一种子生成完全相同的关卡，保证客户端/服务端零漂移。
2. **程序化美术**：所有皮肤/纹理用确定性噪声（ValueNoise/fbm）Canvas 绘制，资产量为零。
3. **服务端权威校验**：成绩提交经 BFS 最短路径 + 路径合法性 + 用时下限三重校验，防作弊。
4. **零 DOM 渲染**：UI 全 Canvas 绘制，为微信移植零成本。
