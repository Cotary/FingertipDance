# 05 — 商业化与埋点

> 广告位设计、变现逻辑、埋点清单。**不做内购**（个人主体拿不到版号）。

---

## 1. 广告位总表

| 广告位 | 微信 API | 时长 | 触发时机 | 收益角色 |
|---|---|---|---|---|
| **激励视频** | `wx.createRewardedVideoAd` | **15s** | ① 关内「提示」首次 ② 关内「跳过」③ 皮肤页「广告解锁」 | **核心收入** |
| **插屏** | `wx.createInterstitialAd` | — | 关卡**结算页**（场景切换时，不打断操作） | 补量 |
| **Banner** | `wx.createBannerAd` | — | 结算页底部 + 皮肤页底部 | 补量（位置不干扰） |

> **15s 的完成率显著高于 30s** → 主用 15s。若广告库存不足可降级到 30s。

## 2. 激励视频流程

### 2.1 通用流程
```
用户点击 → 创建/复用 ad 实例 → ad.show()
  → onClose(res => res.isEnded ? 发放 : 不发放)
  → 失败（load 失败）→ 降级：直接发放 + 提示"广告暂时不可用"
```

**关键规则**
- `res.isEnded === false` 表示中途退出 → **不发放奖励**，但也不能弹惩罚性提示（体验差）
- 广告加载失败要**兜底发放**（否则玩家点了没反应会流失）
- 每次播放前 `ad.load()` 预加载下一条

### 2.2 提示（Hint）
- 每关**第一次**用提示 → 强制看广告
- 同一关第二次起 → 免费（降低逼迫感 + 制造二次播放机会）
- 广告看完 → 亮出 1–3 步提示
- 免费用完后再用 → 再看广告

### 2.3 跳过（Skip）
- 看广告 → 直接判定通关（`steps = shortest`，`skipped = true`）
- 每日每关限 1 次（`skips` 表 + 服务端校验）
- 跳过的关卡：`max_level` 推进，但**该关皮肤不发放**

### 2.4 皮肤广告解锁
- 皮肤页点击「看广告解锁」
- 看广告 → 加入 `unlocked_skins` → 立即装备
- 每种皮肤限一次（已解锁的不再显示该按钮）

## 3. 插屏广告节奏

**只在关卡结算页弹。** 不要在关卡进行中弹。

```
通关 → 结算页入场动画结束(300ms) → 延迟 500ms → 插屏
     → 插屏关闭 → 玩家点「下一关」
```

**频控**
- 同一局游戏内插屏间隔 ≥ 60 秒
- 同一关结算只弹 1 次
- 若 `wx.createInterstitialAd` 不可用（部分基础库不支持）→ 静默跳过

---

## 4. Banner

- 结算页与皮肤页底部，高 80px
- 位置不遮挡主按钮（主按钮在其上方 100px）
- 页面切换时 `ad.hide()`，离开时 `ad.show()`

---

## 5. 广告位与体验的平衡

| 原则 | 具体做法 |
|---|---|
| **不主动打断** | 只在玩家**主动求助**（点提示/跳过）或**场景切换**（结算页）时出广告 |
| **不惩罚中断** | 中途退出广告 → 不发奖但不批评 |
| **失败兜底** | 广告加载失败 → 直接发放奖励 |
| **不刷屏** | 一次通关流程最多 1 个激励视频 + 1 个插屏 |

## 6. 埋点清单

### 6.1 事件总表

| 事件名 | 触发时机 | 关键参数 |
|---|---|---|
| `app_start` | 小游戏启动 | `cold_start`, `version` |
| `login_success` | 登录成功 | `uid`, `isNew` |
| `level_start` | 进入关卡 | `level_idx`, `diff`, `block_count`, `oneway_count`, `w`, `h` |
| `tile_light` | 点亮砖块 | `level_idx`（每关只上报一次，带累计数量） |
| `level_pass` | 通关 | `level_idx`, `steps`, `shortest`, `time_ms`, `skipped`, `stars` |
| `level_fail` | 松手未到终点 | `level_idx`, `steps`, `reached_dist`（离终点最近距离） |
| `level_abandon` | 关卡内退出游戏 | `level_idx` |
| `hint_use` | 使用提示 | `level_idx`, `via_ad`（bool） |
| `skip_use` | 使用跳过 | `level_idx`, `via_ad` |
| `ad_start` | 广告开始播放 | `ad_type`, `placement` |
| `ad_complete` | 广告完整看完 | `ad_type`, `placement` |
| `ad_abort` | 广告中途退出 | `ad_type`, `placement` |
| `ad_error` | 广告加载失败 | `ad_type`, `err_msg` |
| `skin_unlock` | 解锁皮肤 | `skin_id`, `via`（`level`/`ad`/`milestone`） |
| `skin_equip` | 装备皮肤 | `skin_id` |
| `skin_page_view` | 进入皮肤页 | `owned_count`, `total_count` |
| `leaderboard_view` | 查看榜单 | `scope`, `my_rank` |
| `share_click` | 点击分享 | `level_idx`, `score` |
| `share_success` | 分享完成回调 | `level_idx` |
| `challenge_start` | 好友点开挑战链接 | `from_uid`, `level_idx` |
| `challenge_result` | 挑战结算 | `from_uid`, `level_idx`, `win` |

### 6.2 核心看板指标

| 指标 | 计算 | 目标 |
|---|---|---|
| 首关通过率 | `level_pass(idx=1)` / `level_start(idx=1)` | ≥ 95% |
| 各关通过率 | 按 `level_idx` 分组 | 相邻关差异 < 15% |
| 关卡流失热力图 | 按 `level_idx` 分组 `level_fail` 占比 | 无异常尖峰 |
| 提示使用率 | `hint_use` / `level_start` | 早期高、后期低 |
| 广告完播率 | `ad_complete` / `ad_start` | ≥ 75% |
| 激励视频人均次数 | `ad_start` / DAU | 1.5–3 次 |
| 次日留存 | 次日 `app_start` / 当日 `app_start` | > 40% |
| 分享率 | `share_click` / DAU | > 5% |
| 挑战转化率 | `challenge_start` → `challenge_result` | > 60% |

## 7. 埋点实现

- **Web 版**：把事件 push 到内存数组 + `POST /api/report`（后端落 MySQL `events` 表或直接写日志）
- **微信版**：`wx.reportEvent`（需在后台配置事件 ID）或同样走自建 `/api/report`
- **必须本地缓冲**：断网时存 localStorage，恢复后补传
