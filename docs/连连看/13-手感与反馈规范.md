# 手感与反馈规范

> 本文件是 T15「手感打磨」的唯一真相源。所有反馈时序、动画参数、触觉反馈以本表为准。

## 1. 反馈时序表

| 事件 | 视觉反馈 | 时长 | 音效 | 触觉 |
|---|---|---|---|---|
| 按下起点 | 起点放大 1.1× | 80ms | 无 | 无 |
| 点亮砖块 | 砖块变亮 + 顶部高光 + 4 颗粒子迸发 | 120ms | 方波 880Hz 30ms | 无 |
| 断线 | 线头横向抖动 ±4px 3 次 + 红色闪烁 | 200ms | 方波 220Hz 120ms | 短振动 |
| 进入单向块（合法） | 箭头轻微脉冲 | 150ms | 无 | 无 |
| 尝试进入非法格 | 无变化（静默拒绝） | — | 无 | 无 |
| 提示出现 | 目标格黄色描边 + 呼吸动画（1.2s 循环） | 持续 | 无 | 无 |
| 松手未到终点 | 全部砖块熄灭 | 150ms | 无 | 无 |
| 抵达终点 | 冻结输入 + 从终点反向扩散点亮波次（每层 60ms） | ≤1.2s | C-E-G 琶音 | 无 |
| 结算页入场 | 底部滑入 + 背景遮罩淡入 | 300ms | 无 | 无 |
| 皮肤解锁 | 卡片弹入 + 光晕扩散 + 皮肤预览旋转 | 400ms | 1046→1568Hz | 短振动 |
| 进度条填充 | 从左到右填充 | 500ms | 无 | 无 |

## 2. 原则

1. **每个动作 0.1 秒内必须有视觉反馈** —— 拖动时每点亮一格都要有响应
2. **非法操作静默拒绝** —— 不弹窗、不变色、不打断，只在「断线」时给一次明确反馈
3. **失败即反馈** —— 断线要明确告知玩家"刚才那步不行"，但不能惩罚
4. **通关要爽** —— 波次点亮 + 音效 + 震动，三者同时

## 3. 动画参数

| 动画 | 时长 | 缓动 |
|---|---|---|
| 砖块点亮 | 120ms | easeOutQuad |
| 断线抖动 | 200ms | 阻尼正弦 (freq=6) |
| 通关波次 | 每层 60ms，总 ≤1.2s | easeOutCubic |
| 结算页入场 | 300ms | easeOutCubic |
| 皮肤解锁弹窗 | 400ms | easeOutBack |
| 进度条填充 | 500ms | easeOutCubic |

## 4. 触觉反馈（微信）

- 断线：`wx.vibrateShort({type:'medium'})`
- 通关：`wx.vibrateShort({type:'heavy'})`
- 皮肤解锁：`wx.vibrateShort({type:'light'})`

## 5. 实现位置

- `src/render/fx.ts` — 粒子迸发 + 位置扩散环（`Fx` 类）
- `src/render/audio.ts` — WebAudio 合成音效（`Audio` 类 + `audio` 单例）
- `src/game/anim.ts` — 缓动函数集（`Ease`）
- `src/main.ts` — 接入：`session.on` 事件驱动音效/粒子，`frame()` 更新特效，通关波次 `updateWave` 从终点反向扩散，结算页延后 1.2s
