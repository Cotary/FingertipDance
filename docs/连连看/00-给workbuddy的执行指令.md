## 附：给 workbuddy 的三个高频提问的标准答案

**Q: 关卡生成器老是生成不出可解的关卡怎么办？**
A: 看 T05 的 5.1 `generateLevel` 的兜底逻辑。检查三处：① 路径上放单向块时箭头方向是否为**离开方向**（写反直接无解）；② 阻挡块是否把 START 围死了（`protectedCells` 要留出起点四邻）；③ `growPath` 是否因为 `used` 集合太严而走不到 END。先用 `tools/level-inspector.html` 单关调试。

**Q: 服务端和客户端的路径校验规则不一致，导致合法成绩被拒？**
A: `core/solver.ts` 的 `isPathLegal` 与 `server/internal/games/line/validate.go` 的 `ValidatePath` 是**同一套规则的两份实现**。任何一侧改动必须同步另一侧，并各自补测试。规则在 `02-关卡格式与算法规格.md` 第 5.4 节。

**Q: 关卡表生成太慢？**
A: 单关生成应在 10–50ms（求解器 BFS 在 121 格上 <0.1ms）。慢通常是 `narrowBranches` 里反复调用 `solve` 导致的（每轮 3 次求解 × 40 次尝试 × 3 次 narrow = 360 次 BFS）。优化：把 `MAX_ATTEMPT` 降到 20，或在 `narrowBranches` 里复用 solver 结果。
