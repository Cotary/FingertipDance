## 二、必须人做（代码里不假装完成）

### 2.1 运营填值 —— 不填就有功能是空的

| 项 | 在哪填 | 不填的后果 |
|---|---|---|
| **激励视频广告位 ID**（微信 / 抖音各一枚） | `/admin/config` 两平台表单 | 走 `adunit-mock`，**一分钱不赚**，且看广告解锁全部无效 |
| 插屏 / Banner 广告位 ID | 同上 | 展示失败静默跳过（不影响玩法） |
| `rewardedDailyLimit` 建议 3~5 | 同上 | `0` = 不限 → 广告收益没有上限保护，体验也被广告撑爆 |
| `skipDailyLimit` 建议 1~3 | 同上 | `0` = 不限，服务端也不拦 |
| `hintFreeUses` | 同上 | `0` = 第一次提示就要看广告（改造前行为） |
| 主题行 / 皮肤行 id | 同上（主题行旁已印「当前认得的 id：mise / mingsha」） | **写错静默失效**：那套主题永远解不开，也不报错 |
| `shareUrlPrefix` | 同上 | 分享面板提示「分享域名还没配置」 |
| 微信后台：隐私保护指引 | 微信公众平台 | `wx.openPrivacyContract` 打不开；提审判「未接入隐私保护机制」 |
| 微信后台：request 合法域名 | 微信公众平台 | `wx.request` 直接失败 → 线上「能玩但不联网」 |
| 微信后台：类目（游戏-休闲） | 微信公众平台 | 类目与内容不符 → 驳回 |
| 真实 appid（`WX_APPID` / `DY_APPID`） | 构建环境变量 | 占位 appid **能预览、不能上传**（门禁会 WARN） |

### 2.2 资质 —— 缺了包传不上去

- **ICP 备案**：2023 年起国内强制，无备案号不能发布（主体 + 域名都要）
- **软件著作权**：游戏类目几乎必填，周期 1~30 个工作日（加急另算）
- **广告收益 API 权限**：微信流量主 / 抖音 `open.ttgame.mgplatform` scope，有审核等待期
- **未成年人保护 / 实名**：平台托管，但后台要开启对
