# 商业化与埋点（实现落盘）

> 本文件是 `05-商业化与埋点.md` 的执行结果落盘。

## 1. 广告位与触发点

| 广告位 | 类型 | 触发点 | 频控/规则 |
|---|---|---|---|
| `hint` | 激励视频 | 每关第一次点「提示」 | 每关首次提示必须看广告，之后免费（`needsAdForHint`） |
| `skip` | 激励视频 | 点「跳过」 | 每关每日限 1 次（`canSkipToday`/`markSkippedToday`，服务端兜底） |
| `skin_unlock` | 激励视频 | 皮肤页点未解锁的「看广告解锁」皮肤 | 解锁后标记，防重复（`isSkinUnlocked`） |
| `result_interstitial` | 插屏 | 通关结算页入场后 500ms | 60 秒频控（`Ads.lastInterstitialAt`） |
| `skin_banner` | Banner | 进入皮肤页显示 / 离开隐藏 | `openSkins`/`closeSkins` |

## 2. 奖励规则代码位置

- `src/ads/ads.ts` — `Ads` 类：`showRewarded`（含失败兜底 return true）、`showInterstitial`（60s 频控）、`showBanner`/`hideBanner`
- `src/ads/rewardRules.ts` — `needsAdForHint`、`canSkipToday`、`markSkippedToday`、`isSkinUnlocked`

## 3. 广告埋点事件

| 事件 | 参数 | 位置 |
|---|---|---|
| `ad_start` | `ad_type`, `placement` | `Ads.showRewarded`/`showInterstitial` |
| `ad_complete` | `ad_type`, `placement` | 看完 |
| `ad_abort` | `ad_type`, `placement` | 中途退出 |
| `ad_error` | `ad_type`, `placement`, `err_msg` | 加载/播放异常 |
| `skin_unlock` | `skin_id`, `via` | 广告解锁皮肤成功 |

## 4. 关键设计决策

1. **广告失败兜底发放**：`showRewarded` 的 catch 返回 `true`，避免玩家点击无响应。
2. **中途退出不批评**：只记 `ad_abort`，不弹提示。
3. **跳过不发皮肤**：跳过走 `/api/skip` 接口（服务端 `applyProgress` 里 `Skipped` 时不发皮肤），与通关 `/api/progress` 分离。
4. **跳过后 `max_level` 仍推进**：否则玩家卡死。
