# 04 — 美术规范

> 全部**程序化生成**，零图片资源文件。运行时用 Canvas 2D 直接绘制。

---

## 1. 风格定位

**扁平几何 + 圆角方块 + 细描边**（与你的参考截图一致）。
- 无渐变纹理堆砌、无手绘笔触、无角色立绘
- 辨识度靠**形状 + 色相**而非美术细节
- 视觉记忆点：整块棋盘像一块可以拨动的电路板/马赛克

---

## 2. 设计分辨率与布局

- 设计分辨率 **750 × 1334**（竖屏，9:16）
- 实际渲染：`ctx.scale(dpr * (canvasW / 750), dpr * (canvasH / 1334))`
  - 若宽高比不是 9:16，取 `min` 缩放并居中留黑边
- 安全区：顶部 88（状态栏）、底部 120（Home 指示条）

### 2.1 屏幕分区

```
┌─────────────────────────────┐ 0
│  [返回]  第 12 关    [提示][跳过] │  88~200   HUD
├─────────────────────────────┤
│                             │
│         棋 盘 区            │  220~1000  棋盘（正方形，最大边 670）
│                             │
├─────────────────────────────┤
│  皮肤 3/12   ▓▓▓▓░░░░ 28%   │  1020~1120 进度条
│      [下一关]  [分享]        │  1140~1250 主按钮
└─────────────────────────────┘ 1334
```

棋盘边距：左右各 40，棋盘正方形居中，`cell = min(670 / w, 780 / h)`。

## 3. 主色板

```
背景深色   #141824   （整体深色，提升砖块对比）
背景浅色   #1E2436
面板       #262D42
描边       #39415C
主文本     #E8ECF5
次文本     #8A94AD

成功色     #5EA94C
蓝         #6692F5
```

**所有颜色从主色板派生**：每种皮肤给定一个 `hue`（0-360）与 `sat`/`light` 基准，用 `hsl()` 程序化推导高光、阴影、边框。

---

## 4. 格子绘制规格

| 类型 | 视觉 |
|---|---|
| BRICK（未点亮） | 圆角矩形，`cell*0.86`，填充 = 皮肤暗色，1px 描边 = 皮肤边框色 |
| BRICK（已点亮） | 填充 = 皮肤亮色 + 顶部 2px 高光 + 轻微外发光 |
| BLOCK | 深色填充 + 对角交叉线纹理（2 条 1px 线），视觉上"堵死" |
| ONEWAY | 圆角矩形 + 中间一个**箭头三角形**（指向 `dir`），箭头用强调色 |
| START | 圆形，绿色 `#5EA94C`，中心一个「起」字或同心圆 |
| END | 圆形，红色 `#E97E6A`，中心一个「终」字或靶心 |

**已点亮的砖块允许重复经过**，不熄灭（见 GDD 2.3）。

---

## 5. 连线绘制

- 线宽 `cell * 0.16`，圆头圆角（`lineCap='round'`, `lineJoin='round'`）
- 颜色：当前皮肤的主色 + 白色内芯（`shadowBlur = 12` 外发光）
- **拐角处理**：路径中若同一格被经过多次，跳过重复点，不画折角
- **断线瞬间**：线段闪红 3 次（`#E97E6A`），同时线头格子横向抖动 ±4px，共 200ms

## 6. 皮肤系统

### 6.1 皮肤数据结构

```ts
export interface Skin {
  id: string;
  name: string;
  tier: 'free' | 'normal' | 'premium';
  unlockType: 'default' | 'level' | 'ad' | 'milestone';
  unlockValue: number;   // level → 关号; milestone → 关号; ad → 0
  hue: number;           // 主色相
  sat: number;
  light: number;
  texture: 'none' | 'marble' | 'brushed' | 'ice' | 'neon' | 'wood' | 'gold' | 'stardust' | 'galaxy';
  preview?: string;
}
```

### 6.2 皮肤清单（12 种）

| id | 名称 | tier | 解锁方式 | texture | hue |
|---|---|---|---|---|---|
| wood | 原木 | free | 默认 | wood | 28 |
| mint | 薄荷 | free | 默认 | none | 160 |
| graphite | 石墨 | free | 第 3 关 | none | 220 |
| slate | 青岩 | normal | 第 8 关 | none | 200 |
| blush | 藕粉 | normal | 第 15 关 | none | 340 |
| amber | 琥珀 | normal | 第 25 关 | none | 42 |
| marble | 大理石 | normal | 第 40 关 | marble | 40 |
| brushed | 金属拉丝 | normal | 第 60 关 | brushed | 210 |
| ice | 冰晶 | normal | 第 90 关 | ice | 190 |
| neon | 霓虹 | normal | 第 130 关 | neon | 285 |
| gold | 黄金 | premium | 通关 200 关 | gold | 45 |
| stardust | 星尘 | premium | 通关 500 关 | stardust | 265 |
| galaxy | 星河 | premium | 通关 900 关 | galaxy | 255 |

> 实际清单以 `T16` 落地为准，可增删，但**必须同时覆盖三种解锁方式**（default / level / milestone），且**广告解锁档至少 3 种**（把上表中 tier=normal 的部分改为 `unlockType: 'ad'`）。

### 6.3 纹理函数库（`render/skins/textures.ts`）

全部为**确定性纯函数**：`(ctx, x, y, w, h, seed) => void`，在格子内绘制纹理。

| 函数 | 实现要点 |
|---|---|
| `none` | 纯色 + 顶部高光渐变 |
| `wood` | 3–5 条正弦扰动的深色横纹（用 `sin(x*0.15 + phase)`） |
| `marble` | 2 层 value noise + `turbulence`，用亮度阈值切成脉络 |
| `brushed` | 大量 1px 水平线，透明度随机（用 `seed` 决定） |
| `ice` | 2–3 条斜向亮线 + 中心菱形高光 |
| `neon` | 深色底 + 边框 `shadowBlur=16` 发光 + 中心一条亮线 |
| `gold` | 斜向渐变（3 段亮暗）+ 一条斜向高光带 |
| `stardust` | 深色底 + 20 个 1–2px 亮点（位置由 seed 决定）+ 缓慢闪烁（时间参数） |
| `galaxy` | 深色底 + 多层径向渐变（紫→蓝）+ 星点 + 随机云雾斑 |

**噪声实现**：自写一个 2D value noise + fbm（约 40 行），种子化，保证同一格每次渲染一致。

### 6.4 皮肤预览页（`ui/skins.ts`）

- 网格展示全部皮肤，已解锁的可点击装备，未解锁的显示**锁图标 + 解锁条件**
- 卡片下方用**真实渲染**画一个 3×3 的小棋盘预览（不是图片）
- 广告解锁的皮肤显示「看广告解锁」按钮

## 7. UI 规范

### 7.1 按钮
- 主按钮：圆角 24，高 88，`#6692F5` 底，主文本 32px
- 次按钮：描边式，透明底 + 2px 描边
- 按下态：缩放 0.96 + 透明度 0.9，80ms

### 7.2 字体
- 系统字体栈，不引入字体文件（微信无自定义字体成本）
- 字号阶：`12 / 14 / 18 / 22 / 28 / 36`

### 7.3 动画节奏（与 `05-商业化与埋点.md` 的反馈时序表一致）
| 事件 | 时长 | 缓动 |
|---|---|---|
| 砖块点亮 | 120ms | `easeOutQuad` |
| 断线抖动 | 200ms | 阻尼正弦 |
| 通关波次点亮 | 每层 60ms，总 ≤ 1.2s | `easeOutCubic` |
| 结算页入场 | 300ms | 底部滑入 |
| 皮肤解锁弹窗 | 400ms | 弹入 + 光晕扩散 |
| 进度条填充 | 500ms | `easeOutCubic` |

## 8. 音效

无音频文件 → **用 WebAudio 合成**（微信侧用 `wx.createInnerAudioContext` 需要文件，所以微信版改为短促的振动反馈 `wx.vibrateShort` + 静音；或后续补 mp3）。

| 事件 | 合成参数 |
|---|---|
| 点亮砖块 | 方波 880Hz，30ms，音量 0.15 |
| 断线 | 方波 220Hz，120ms，带 20ms 抖动 |
| 通关 | 三角波 C-E-G 琶音，每音 100ms |
| 解锁皮肤 | 正弦 1046Hz → 1568Hz，300ms |

## 9. 分享海报（`ui/share.ts`）

- 尺寸 750 × 1334，运行时用离屏 canvas 绘制
- 内容：大号「第 N 关」+ 当前皮肤渲染的一小块棋盘 + 头像 + 昵称 + 一句挑战文案
- 文案池（随机）：`我卡在第 27 关，你能连过去吗？` / `这关我用了 38 步，你呢？` / `敢不敢试试我的皮肤？`
- 输出：`canvas.toTempFilePath()` → 微信分享或保存到相册
